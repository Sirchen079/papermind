# 条件与结论复核

PaperMind 改编版，源自 K-Dense scientific-critical-thinking（MIT）；上游版本及修改说明见 THIRD_PARTY_NOTICES.md。


对比较、归因和优劣判断做下列检查；单纯摘取数值不必扩展成方法学审稿。

1. 明确要判断的是描述、关联、方法优劣还是因果，依据材料作答，而不是沿用问题中的预设。
2. 按 [比较条件检查表](references/comparison.md) 挑出与本题相关的几项，对所有方法用同一标准，区分“明确不同”“未报告”“已匹配”。
3. 给出判断：条件大体可比时直接说哪种方法更好、好在哪里；条件不同时点明主要差异，仍给出倾向性判断及其成立前提。尚待验证的解释写成假设，并给出能检验它的实验。
4. 不补写论文没有给出的统计量。

纠正历史回答时引用当前可用来源，直接改正过强的表述。所提新实验是计划，不是已完成的证据。按用户问题和既有输出 schema 给出简洁结果，不额外生成图示、外部检索、评审等级或固定长报告。

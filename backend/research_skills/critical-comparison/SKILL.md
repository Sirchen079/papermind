# 条件与结论复核

PaperMind 改编版，源自 K-Dense scientific-critical-thinking（MIT）；上游版本及修改说明见 THIRD_PARTY_NOTICES.md。

对比较、归因和有效性判断执行下列复核；单纯摘取数值不必扩展成方法学审稿。

1. 明确待判断的主张是描述、关联、方法优劣还是因果；从逐篇证据底稿取得支持，而非从问题中的预设取得答案。
2. 按 [比较条件检查表](references/comparison.md) 检查本题相关项目。对所有方法使用同一标准，区分“明确不同”“未报告”“已匹配”。
3. 判断证据能否区分备选解释。报告数值较高不自动说明方法更好；条件差异说明比较受限，只有相应受控对照才能将差距归因或量化贡献。待验证解释标为假设，不作为结论。
4. 输出与证据匹配的判断，并指出具体缺口或下一步验证动作。缺少不确定性信息不能补写统计量，不能推断显著、不显著、无效或不存在。

纠正历史回答时引用当前可用来源并明确收回过强表述。所提新实验是计划，不是已完成的证据。按用户问题和既有输出 schema 给出简洁结果，不额外生成图示、外部检索、评审等级或固定长报告。

你是一名研究生的组会汇报人。请把下面的「本周统计」改写成一份中文 markdown 组会汇报。

写作要求：
- 一级标题格式：# 组会汇报（起始日期 至 结束日期），日期取统计区间；
- 五个小节缺一不可，二级标题依次为：## 本周进展、## 文献收获、## 实验进展、## 问题与求助、## 下周计划；
- 只使用「本周统计」中出现的数字与条目，不得编造；某类数据为零时该处写「本周暂无」；
- 「本周进展」综述入库/阅读/笔记数量与 Idea 推进；「文献收获」重点列新入库与雷达高相关论文；「实验进展」围绕实验新建、日志与完结情况；
- 「问题与求助」必须原样保留用户填写的问题（若有），并为每个问题写出具体求助请求；未填写则写「本周暂无」；
- 「下周计划」基于本周数据给出 2-4 条具体、可检验的安排；
- 直接输出 markdown 正文，不要任何解释，不要代码块标记。

# 对话基本体验改进（2026-09-19）

## 本轮问题与结果

旧版只有文字输入框，图片能力是模型配置标记，没有图片或文件发送链路；工具运行前没有状态，停止主要中断前端连接，到轮次上限后只能重新执行。自定义模型明确设置的思考等级也可能被 LiteLLM 的模型目录静默丢弃。

现在支持以下实际操作：

- Ctrl+V 粘贴剪贴板图片、拖入文件、附件按钮多选；可预览、移除、仅发附件。最多四个附件，每个原始文件最多 10 MB。
- 图片归一化为 PNG，按多模态内容发送。PDF、DOCX、TXT、Markdown、CSV 及常见代码文件提取文字；文件内容可预览，每个最多 60000 字符，超过限制明确拒绝而不静默截断。扫描版 PDF 提示改用截图。PDF/DOCX 中的图表并不自动转换为图片。
- 附件保存在原消息请求中，刷新历史和重试都保留，不依赖临时文件。未发送附件和消息队列使用 IndexedDB 本机保存，按资料库、项目和对话隔离；恢复失败或保存失败会明确提示。恢复队列默认暂停，不自动发送。浏览器清理站点数据仍会删除草稿。
- 对话区直接选模型、编辑上下文窗口／思考等级／图片能力；选择仅影响本次对话调用，配置编辑沿用已有模型配置与共享连接同步规则。未知图片能力与明确不支持区分显示。
- 显式思考等级不会因自定义模型不在 LiteLLM 内置目录而被忽略；不支持的参数由服务商返回真实错误，用户可改回“自动”。
- 多模态内容兼容 Chat Completions、Anthropic 的 LiteLLM 入口和 Responses 输入转换；上下文估算不把图片 base64 当作普通文字。
- 生成时显示当前轮次、模型等待、正在执行的工具与核对阶段。停止通过后台取消标记，在下一次工具或模型调用前生效；无法撤回已执行工具，也不能保证立即中断服务商正在处理的请求。
- 达到工具轮次上限时保存消息、完整工具结果、证据与引用，点击“从已保存进度继续”恢复，不重复先前已完成的工具调用。此续接针对轮次上限；普通停止和网络错误仍显示重试。
- 工具卡片随最终回答持久化，重新打开对话可查看。上翻历史时不再被新状态强制滚回底部。

## 第二批：队列、草稿与上下文（2026-09-19）

- 生成期间可继续打字、贴图、添加附件、选择下条消息的模型与技能，最多排队 10 条，保持先后顺序。每条保存入队时的模型 ID、附件、论文摘录及技能 ID；后续选择变化不会串到已排队消息。
- 队列可暂停、继续、移除、放回空输入框修改。只有正常完成当前回答才自动发送下一条；停止、错误、连接中断、需要用户澄清都会暂停。刷新、离开页面再返回或切换对话后默认暂停。
- IndexedDB 保存附件和队列；首次恢复完成前禁用相关操作，保存失败显示提示并保护页面关闭。发送队列项前先持久化发送状态，收到服务端 accepted 后移除；接收状态不明的项不会自动重发，需检查历史并使用原消息重试。该机制不是跨多个浏览器窗口的分布式队列。
- accepted 只清理匹配的已发送草稿，不覆盖用户刚输入的新文字或后来新增的附件。后台回执更新原对话草稿；重新打开页面时，仍在运行的任务可停止。
- 显示上次请求后端消息的 token 估算，包含系统提示、材料和工具结果，不把图片 base64 算成文本。明确标注不包含工具定义和输出预留，不能当作服务商计费值。较早历史被摘要或被移出上下文时给出不同提示，历史记录本身不删除。
- 窄窗口中输入框独占一行，按钮放在下方，避免附件／排队／停止按钮将输入区挤成竖排。
- 修复复制失败没有反馈、上下文压缩过程中点击停止后仍可能继续调用模型的问题。

### 第二批验证

- 前端 130 项测试通过，新增 FIFO、多条保留、暂停／阻塞、发送状态不明、精确移除与队列上限测试；生产构建通过。
- 后端附件与上下文状态 20 项测试通过，agent 上下文／轮次上限／失败边界／澄清／聊天 API 回归 48 项通过。
- 实际浏览器 + 独立数据目录 + 模拟模型：连续三条按序完成；停止后队列暂停；生成期间粘贴截图；刷新与重启预览后恢复截图和暂停队列；不同对话不串草稿；模拟服务商错误暂停；队列消息放回输入框；ask_user 澄清阻止后续队列。
- 使用的是标准 PNG 剪贴板，仍未验证微信客户端的特殊剪贴板格式。此次依旧为源码与本地预览更新，未打包、安装或替换远端 0.5.3。

## 聊天复核失败的降级修复（2026-09-20，尚未重新打包）

用户遇到“证据复核未完成，未发布未核对草稿：Expecting value…”：原实现将复核返回格式与聊天发布强绑定，空正文／非 JSON／格式错误会导致已生成的答案整条丢失。解析失败本身并不证明回答有事实错误。

- 复核成功时继续应用已通过来源与定位校验的修改。
- 聊天复核失败时保留原回答及引用，开头明确提示“自动证据复核未完成”，同时保存 unavailable 审计状态；不再返回生成失败或要求重跑整条任务。
- 兼容 JSON 代码围栏及前后解释文字，不猜测截断 JSON，不应用无效修改。
- 降级仅用于聊天；专题知识原有的严格复核约束保留。主动停止、主回答为空、主模型调用错误仍按原本的失败语义处理。
- 新增空响应、非 JSON、超时、无效定位、复核容量不足、主动停止、流式／非流式持久化测试。
- 验证结果：聊天／复核／失败边界相关 85 项通过，专题知识及引用 24 项通过。

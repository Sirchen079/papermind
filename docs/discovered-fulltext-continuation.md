# 已发现全文接入持续研究

2026-09-26 开发源码验收。本轮解决一处已发生的使用断点：agent 已找到可访问的论文 PDF，却因普通网页读取器的 10 MB 限制，把下载和上传重新交给研究者。现在可直接将原文附到当前论文，继续按章节阅读、保留页码，并沿用原有成果保存与修订流程。用户无需增加一个下载工具或自行部署服务。

这轮流程通过不等于研究内容全部正确。真实模型的科学判断仍有过度推断，原回答保留，另存署名核对稿。没有据此宣称全自动综述质量、千篇全部理解、竞品领先或真实研究者节省工时。

## 使用架构与复用取舍

主路径仍为“问题 → 找材料 → 阅读比较 → 可回查成果 → 纠正并继续”。新能力接在找材料和阅读之间，共用原论文对象、全文页码、混合检索、PDF 阅读器、文档版本及恢复机制。不会把一次下载另建成独立科研入口。

先检查 Nature Downloader 的 OA 获取和交付验证方法，以及现有 Python 导入、解析和索引实现。借鉴直接正文链接、真实 PDF/页面检查、来源与时间/大小/哈希回执。Nature 的 Node 直接下载助手会把响应全部读入内存，不适合直接复制到这次大文件路径；本项目复用已有 HTTPX 依赖的[流式响应](https://www.python-httpx.org/quickstart/#streaming-responses)，在磁盘临时文件中处理，随后进入既有导入器。没有复制外部项目代码或引入新依赖。

实现与分工：

- `import_paper_pdf` 接收已发现的公开正文直链。已有论文使用其 ID 附全文，保留已整理的元数据；新论文复用现有查重和导入逻辑。已存在本地 PDF 时直接复用。
- 下载流式落盘，格式和解析确认后才写入论文。中断、坏文件或 HTML 登录页不会破坏已有材料；临时文件在退出时清理。没有把网页或聊天附件的内存上限扩大为全文方案。
- 新全文先建立本地片段，再使用已配置的向量模型建索引。向量服务失败时，保留原文、页码与本地检索，局部说明状态，继续允许阅读和输出。
- 下载回执独立保存为 PDF 旁的 `.source.json`，包含来源、获取时间、字节数及 SHA-256。实际读到的正文仍由现有来源机制记录。下载成功本身不作为已读整篇的证据。
- 普通网页工具遇到大 PDF 时提示 agent 走现有本地全文路径；工具取消、检查点和重试复用既有机制。未增加逐阶段审批或全局质量拦截。

源码入口：[下载](../backend/app/ingestion/pdf_download.py)、[接入论文及索引](../backend/app/agent/paper_acquisition.py)、[共用导入器](../backend/app/ingestion/service.py)、[测试](../backend/tests/test_paper_acquisition.py)。原有项目和应用备份会遍历 PDF 目录，旁存回执可随之进入备份；本轮未另做完整恢复实测。

## 真实 FWI 任务

在上一轮隔离项目的副本中继续同一对话。库中有原 1000 篇论文和 P1001 的 GSOT 元数据；P1001 尚无全文。本轮提供上一轮已经找到的 [HAL 作者稿直链](https://hal.science/hal-03404483v1/file/manuscript_revised_r2.pdf)，要求接入 P1001 并核对预处理、内部尺度、对照条件和噪声结论。没有提示具体工具名或正确科学结论。本轮不重新验收外部论文发现。

GLM 自行选择 `import_paper_pdf`，导入后读取目录、§2.3、§4.1、§4.2、§3.2，并通过正文检索查噪声。`noise` 在所选 §3.1 范围的精确查询未命中，随后改用语义检索。完整过程使用用户已配置的真实 API。

## 科学内容审计与修订

这次产品 GLM 没有实际加载 Nature 技能，不能把开发时参考 Nature Downloader 说成模型执行了该技能。Codex 在验收中参考 Nature Paper Card 的原文事实、分析与假设区分，并运行其原装 `prepare_paper.py`：29 页、校验有效。未运行完整 16 节精读卡或三位独立审稿流程。脚本没有识别出图表，且一个印刷页标签误识别为图中数值，故仅采用核对过的 PDF 文件页；表 2 另在阅读器中直接查看。

| 原始回答中的判断 | 核查与处理 |
|---|---|
| 外部预处理和 GSOT 内部尺度分开说明 | 主干有原文依据。外部为去直流、√t 校正、谱白化、带通和道集 RMS；内部另有 τ/A 和恢复 AVO 的道权。定位 PDF 7、13–14 页。 |
| “τ=dt 即 L2”，并据此建议我们的对照 | 超出该例证据。§3.2 说在其测试中模拟 L2 行为；§2.3 的常规 L2 残差恢复条件是恒等匹配。核对稿保留条件，要求另核对 L2 实现和缩放。定位 PDF 8、10 页。 |
| “噪声的实质讨论仅 §5.1.3” | 不成立，§3.2 与 §4.2 也明确讨论。§3.3 的合成实验明确无噪声且已知震源；实测应用不能单独建立受控定量抗噪优势。定位 PDF 10、11、14 页。 |
| 实验计划“应沿用逐阶段 τ 衰减” | 对当前问题的适用性尚未论证。该文合成例全程 τ=4 s，实测才递减；先保留现有匹配组与问题，固定 τ 选择规则，必要时另做参数安排比较。 |

原始回答为消息 39，原样保存为消息 40，核对稿为消息 41。核对稿正文及记录明确署名 Codex、未获研究者采用，并保留原稿、父版本及新增 PDF 7、8、10、11、13、14 页的来源片段。保存和修订没有再次调用模型；修订前 39 条消息及 5 份导出不变。原始科学错误没有用更理想的重跑结果替换。

保存调用复用原有回答保存接口；署名核对稿复用版本服务的来源补充和署名记录能力。当前普通版本卡片仍统一标为人工修订，专用 AI 审核署名并非本轮新增的产品流程。验收时以正文署名和记录区分，不能声称这是研究者亲自完成或批准的修订。

## 下一优先级

材料已能接入，但“查到、读到、确立结论”在呈现中还不够清楚。上一轮候选元数据和网页搜索结果仍可出现在依据列表；本轮观察到继承的网页结果继续跟随核对稿。这会增加研究者判断证据的成本，应先复用现有来源类型和读取记录改善依据呈现，而非再加一轮强制审批。

继续验收关键判断的核查与修订成本、沿修订稿的正确接续，以及新材料加入后是否只更新相关部分。达到行动上限时交付已完成部分的缺口仍保留，复用调研见[按需检索验收](agent-directed-retrieval.md)。这些任务优先于新增独立功能入口。产品标准是研究者能少做多少重复工作，同时容易发现影响研究决定的错误。

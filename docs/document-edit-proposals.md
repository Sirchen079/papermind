# 从核查建议到采用局部修订

2026-09-26，未发布源码。接续[选段核查](document-passage-check.md)：研究者不必再把 AI 建议复制出来、找到整份笔记中的对应段落，然后重存全文。

## 协作流程

Agent 回读保存的文档和相关来源后，可通过 `propose_document_edit` 生成局部修改卡。卡片并排显示原段落与建议段落，说明改动依据，支持直接编辑建议、预览排版和恢复原建议。用户点击“采用并保存新版本”后，系统只替换该处，保存完整新版本；原稿和其他段落保留。

建议生成不写文件、不调用额外审查模型。若原文定位不唯一，工具返回可继续定位的位置，agent 可以补读或指定位置，普通回答仍可继续。匹配对象是指定版本的原始 Markdown，避免将渲染后选文误当成源文件内容。

新版本保存在当前研究对话中，即使原稿来自另一个对话。它保留原版本的来源及提出建议时补查的来源，可在文档目录继续查找、下载、再编辑，并作为用户采用的修订进入后续研究上下文。用户在卡片里的修改随刷新保留；保存失败可重试；重复提交同一采用操作复用已保存版本。将建议改回原句时不会生成空变化版本。

连续采用同一文档的不同建议时，以当前对话中这份文档的最新修订继续修改，保留此前采用及人工编辑的其他内容。先按原版本核对建议，再定位最新版本中未改变的目标片段；若目标本身已修改，保留建议文字供用户回读调整。每次仍另存版本，版本名称沿用同一个基础文件名，避免反复追加后缀。

## 真实模型与界面验证

使用实际 UI 选段请求、千篇库隔离副本及用户配置的智谱 Responses、GLM-5.3 low 运行。模型依次读取原研究稿、网页来源，生成一次可定位的修改建议，最后回复；4 次文本调用，22.8 秒，28759 tokens，未调用向量或重排。生成建议后所有原文件哈希不变。

本次模型仍将 README 的示例参数称为“默认设置”，因此没有把原始建议记为事实质量通过。界面验证直接使用这份真实建议，先将“README 的推理脚本默认为”改成“README 的推理示例采用”，再采用修改。没有提前修好模型输出或用手写成功响应替代真实建议。

在关闭模型提供商的界面副本中，已验证：

- 原段落和建议段落与实际工具参数一致；修改、预览及刷新后恢复正常。
- 模拟 503 后编辑内容保留，可刷新后继续重试。
- 保存的新正文严格等于原文只替换目标片段，原有全部导出文件字节不变。
- 刷新后仍显示“已采用”，新版本能下载，在文档目录中可查，并保留网页原文快照。
- 人工采用与保存阶段没有模型调用；无浏览器异常或 390px 横向溢出，桌面及窄屏截图已查看。

首次下载比较失败是 Windows 文件 CRLF 与数据库 LF 的差异，逐项核对后确认仅有 21 处换行差异；按既有下载测试统一换行后重跑通过。响应式截图曾截到侧栏过渡动画，补充布局稳定条件重新回放，未为通过测试修改产品布局。最终界面记录位于 `F:/论文管理/document-proposal-ui-20260926-v3`，模型原始请求、响应和建议位于 `document-proposal-live-20260926`；这些私有测试数据不交付。

## 回归与适用边界

前端 141 项测试及生产构建通过。后端分组覆盖 52 个不同用例：文档版本、来源、实际工具调用、同步与流式传输、重复原句的指定位置、跨对话采用、源版本变化或删除、失败重试、段落删除、无变化操作、用户改写建议、重复采用及后续上下文。第一组 28 项通过；第二组除工具数量断言仍期待 24 项外，29 项通过。更新新增工具的注册预期后，整个工具模块 19 项通过；原失败日志保留，未将其重写成全绿。未重跑完整后端回归。

本轮没有测量科研人员的真实主动操作时间，也没有证明模型能独立消除全部事实错误。它验证的是可用的协作步骤：AI 提出修改，人能直接纠正和采用，材料与依据继续留在同一工作流里。原文匹配只证明改动位置，不证明建议科学上正确。

新功能尚未重新打包，已交付的 0.6.10 安装程序不含修改建议卡。既有手工整篇编辑、另存文档及普通对话仍可使用。

## 连续采用缺陷与修复

后续真实三篇比较产生四条修改建议。连续采用两条时，第二份版本没有包含第一处修改：两次均从原始稿另存，形成平行版本。原文件没有丢失，但研究者需要手动合并，不能算连续修订成功。独立回归用例同样失败。

源码已改为保留当前对话的已有修订并定位未改变的目标；首轮 9 项测试通过。实际四条建议在隔离对话中重放，并人工改写其中一处过强措辞，四次保存均严格等于累计的局部替换，最终保留全部四处修改、历史文件与三篇来源；采用阶段零模型调用。版本文件名保持稳定基础名。最终相关回归 28 项通过（153.75 秒），覆盖重复段落按两种顺序采用、重试、人工修订及文档目录。旧冻结安装包不含这次修复，正在重新构建。详见 [三篇比较与修订实测](research-comparison-collaboration.md)。

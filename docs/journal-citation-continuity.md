# 期刊引用信息贯穿导入、编辑和导出

2026-09-27，0.6.19 后的源码迭代，尚未进入新安装包。

研究任务中找到论文、取得原文之后，用户仍需把参考文献带入写作软件。原实现只保留题名、作者、年份和期刊等基础字段，BibTeX/RIS 中已有的卷、期、页码在入库时丢失，后续导出也无法恢复。此次修复这段流程，减少人工从出版网页重新抄录引用信息的工作。

## 复用与实现

- 已检查内置 Nature Academic Search 的 `scripts/format-converter.py`：已有 DOI → Crossref → 引用格式的可用思路。项目自身已有 BibTeX/RIS 解析器、PDF 下载、元数据编辑、跨项目复制和引用导出。
- 使用 [Crossref 官方内容协商接口](https://www.crossref.org/documentation/retrieve-metadata/content-negotiation/)的 BibTeX transform 路径，直接复用项目已有 `bibtexparser` 解析结果，没有复制外部实现或新增依赖；没有修改 Nature 原文件，也未声称本轮 Agent 执行了科研 skill。
- 新的已知 DOI 公共 PDF 导入可补齐作者、年份、期刊、卷、期、页码。官方 arXiv PDF 仍沿用已有 arXiv 元数据路径。已整理的记录不被自动覆盖。
- 新增可空字符串字段 `volume`、`issue`、`pages`，贯穿 BibTeX/RIS 导入、持久化、手动创建 API、元数据编辑、JSON/BibTeX/RIS 导出及既有跨项目复制。保留 S/R 前缀页码和文章编号；RIS 的简单起止页范围可规范为双连字符。
- DOI 元数据检索失败只记录局部状态，不阻断 PDF 阅读和入库。没有额外模型调用、审批或全局写作门槛。

## 范围与后续

本次只自动补充**新记录的已知 DOI 公共 PDF 导入**；普通拖入 PDF、已有记录批量补齐、DataCite 等其他注册机构、多种文献类型的完整 CSL 映射不在本次实现中。旧导入已经丢失的卷期页码不会凭空恢复，仍可通过元数据编辑或重新导入完整引文修正。

产品下一步应回到完整研究任务：让研究者更容易找回、核对、采用并继续使用已有研究成果，观察减少了哪些实际操作。当前是引用信息完整性的基础修复，不能据此宣称优于 Zotero，或已经证明综述质量、人工提效。

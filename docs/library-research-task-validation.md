# 从千篇库完成一项研究任务

2026-09-26，未发布源码实测。验收围绕减少研究者查找、阅读、比较和修改的工作量，不要求自动完成整篇综述。

## 任务与实际调用

新建空白对话，不指定论文。要求在现有千篇库查找三篇上下文压缩论文，回读方法，比较输出形态、问题相关性、训练及推理条件，并在“不训练、普通文本 API、可用现成小模型”的条件下提出实验，保存一页左右研究笔记。事先冻结三篇候选的原文检查记录，未提供给模型，也不要求模型选中相同论文。

使用隔离数据库及用户已有连接，智谱 Responses `glm-5.3`、low。共 7 次文本调用，61.28 秒，记账 93873 tokens。工具执行两次 `search_library`、六次 `get_paper_full_text` 和一次 `save_document`，选择 TCRA-LLM、CompAct 和 SEER。保存成功且没有强制澄清或拒绝。

测试副本显式配置大模型重排，但本次 agent 选择了关键词元数据搜索和全文读取工具，没有调用正文向量搜索，实际 embedding 和 rerank 调用均为零。因此本例证明的是 agent 的关键词查找与阅读流程，不能写成“向量加重排端到端验收通过”。没有改动用户的原始配置。

原始请求、响应、工具记录、输出和预先冻结的标准位于本机 `F:/论文管理/library-research-compression-20260926`，包含私有测试数据库，不纳入交付。原稿保留，没有人工修正后冒充模型输出。

## 对产物的核查

有效成果：找出三篇相关文献，保存方法比较、未压缩对照及待验证改造；没有跨论文分数排名。CompAct 的迭代压缩、Mistral-7B 压缩器与训练数据规模等主要信息读到了对应原文。

尚未达到质量验收：

- **关键角色混淆。** 笔记把 SEER 的生成器写成固定 Llama2-7B-Chat。PDF 第 2 页该名称指抽取器；第 6 页明确用 Flan-T5-XL 和 Llama2-7B-Chat 两种生成器评测。模型只读取 SEER 第 1–3 页，未继续查实验配置。
- **部署结论过早。** “强版本都要训练，我们全部不可用”没有区分论文训练过程与使用已训练权重。尚未查权重可得性，不能断言不可部署，也不能反过来宣称一定有可用权重。
- **抽取不等于保真。** “不改写故数字保真”忽略模型仍可能改写、漏句，以及单位、否定和限定条件分布在相邻句、表头或脚注中的情况。保留某个数字的字面形式不能证明回答正确。
- **引用精度不足。** TCRA 的训练和词删除机制大多指向第 1–2 页介绍，未回读第 5–6 页的方法与实现；CompAct 的会议写成 ACL 2024，而 PDF 首页是 EMNLP 2024。
- **成本与人的工作没有完整计入。** 把不同模型 token 数相加不能直接当作费用；未计清生成与压缩输出 token、本地推理时间和总延迟，缺少人工检查、纠正负担的测量。不能从 61 秒生成推导节省了多少人工时间。

本例记为“流程完成，内容仍需修正”，不计为可直接采用的研究建议。SEER 是模型自行选中的新候选，其原文在生成后另行核查，不能称为预先盲标。

## 根因判断与后续实现方向

这次不是检索完全失败：相关论文已找到，部分正确原文也进入上下文。主要问题是阅读停留在介绍、跨段关系解释错误，以及把方法借鉴直接写成已经成立的保证。仅扩大向量召回或增加拒绝条件都不能覆盖这些问题。

下一步围绕会改变研究决策的事实组织阅读：例如抽取器与生成器各是谁、训练发生在哪个模块、能否使用现成权重。让 agent 按这些缺口继续读取方法和实验配置，保留实际出处和适用条件；先产出可讨论的比较，允许局部补查与修改，不强制每篇全文精读，不以所有字段齐全作为输出门槛。抽取与摘要方案都必须实测，不能在产品中把词表或数字一致性检查包装成事实正确性保证。

已有人工修订、历史来源和跨对话复用继续作为协作入口，不另建重复工作区。后续验收应同时记录任务完成程度、关键错误与纠正步骤、研究者主动操作时间和模型等待成本；总体优势尚未得到同任务人工或竞品对照证明。

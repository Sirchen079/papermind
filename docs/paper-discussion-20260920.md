# 基于所选论文讨论

论文库勾选若干论文后，点击“基于所选论文讨论”，创建普通 AI 对话。保留原“围绕问题比较”入口，分别用于自由讨论和结构化研究。讨论最多可关联 100 篇论文，不沿用结构化比较的 5 篇限制。

- 论文集合持久化到 Conversation.paper_ids_json；旧单篇关联保持兼容。已有数据库启动时通过迁移新增字段，保留原有对话、论文关联和自增 ID。
- 对话显示论文标题与逐篇准备状态，后台复用或补解析全文。错误显示在对应论文旁，可重试；没有 PDF 的论文仍可使用摘要、已有总结和笔记讨论。
- 后续提问、刷新、重新打开、发送队列和失败重试携带原论文集合。重试使用原请求快照，不因当前 UI 选择变化而换论文。
- 模型获得完整论文 ID／标题清单，以及有总预算的摘要和研究笔记；需要全文时复用既有全文工具。自动向量检索先限定所选论文再排序，不混入未选论文的检索结果。
- 提示模型标明具体论文、区分推断与原文，允许讨论 idea 和主动询问研究背景；不要求先完成比较报告或额外证据复核。
- 论文删除后显示不可读，剩余论文仍可讨论。退出论文上下文清空后续关联，不改写已有历史。多篇讨论保存笔记时不默认归入第一篇。
- 此次提供创建集合和整体退出；未增加对话中逐篇增删集合的编辑器。

# Agent 原文定位与后文补读

2026-09-26，未发布源码，接续[千篇库研究任务核查](library-research-task-validation.md)。

此前 `get_paper_full_text` 的短语查找只给出第一次命中附近的正文。方法名称和常用词往往在摘要、引言里先出现；反复换关键词仍可能读不到方法与实验配置。已有语义正文搜索可解决概念检索，但精确阅读工具缺少直达后文的线索。

现在同一查询返回主要摘录、命中数量、下一处未读命中的偏移，以及最多八个其他位置的短原文预览。预览按 PDF 页分散选择，超过八处时也保留靠后的定位点，便于发现附录里的实现细节；没有页标记时按文本区域选择。每个预览保留独立的原始偏移和真实页码。模型可以继续按偏移阅读，也可以直接指定 `page` 读取某一 PDF 页。跨行空白不再打断普通短语匹配，偏移仍指向未经改写的原始文本。

`page` 指 PDF 抽取标记中的页码，不猜正文印刷页码；没有对应标记时仍可使用偏移和正文搜索。指定页码的查询只在该页内查找，后续可省略 `page` 并使用 `next_start_char` 继续。未增加模型调用、强制精读或确认步骤。页内内容超过既有单次长度时，继续使用偏移读取。

预览确实提供给了模型，因此作为独立短摘录保存进来源记录；它们的页码不并入主要摘录，不能把页间未读的全文冒充已读。旧读取参数、无页标记文本及现有历史来源仍可用。聊天指导补充按影响当前决策的事实读取方法和实验设置，并区分模块角色、训练与使用条件，不要求所有字段齐全才输出。

# PDF 导入、全页 OCR 与 Markdown

新 PDF 保存后，默认把每一页交给已配置的 OCR 模型。全部页面转换完成后，Markdown 保存到本机，作为 AI 阅读的正文，并自动建立本地关键词和向量索引。论文库上传、公开 PDF 获取、文献调研导入使用同一条流程。

在「设置 → 文档与检索」配置自己的模型连接，添加支持图片输入的 OCR 模型并选中。尚未配置时，PDF 仍会保存，转换显示等待配置；选择模型后自动继续。没有内置供应商账号、API key 或用户连接配置。OCR 与向量调用使用用户自己的服务和额度，无需部署主应用服务器。

导入后会打开论文详情。点击「OCR 与 Markdown」查看逐页进度，完成后入口变为「Markdown 原文」。可以下载 Markdown，或下载 Markdown 与原图；正文中的原页链接用于核查表格、公式和模糊文字。AI 的全文读取与页码检索使用这份已保存的 Markdown，不把等待识别的页面作为已读证据。

关闭面板后任务继续，应用重新启动会继续尚未完成的导入；已完成页面有本地缓存，普通继续转换复用缓存。取消或失败保留 PDF、已完成页面与此前发布的正文，可在面板重试。「重新识别全部页面」会重新调用模型。既有论文不会在升级时自动重识别；重复添加已有 PDF 保留已有正文。

项目可明确改选「自动：文字页提取，扫描页 OCR」、可选高级解析服务，或直接原生提取。这些是用户选择的替代方式；默认全页 OCR 不在服务失败时悄悄改成原生提取。

实现复用既有转换线程、页码缓存、模型连接和检索索引；HTML 表格转换复用 MIT 许可的 markdownify 与 Beautiful Soup，许可证随包附带。长表格分块按整行切分并重复表头、保留近邻表题；公式块保留完整内容。处理只规范模型输出结构，不修改模型识别的词语和数值。

识别质量仍取决于模型。实际原页对照发现模型会读错合并表头、数字或方法名，完整转换和检索成功不代表科学内容已核验。涉及实验比较和结论的关键值，请利用保留的原页检查。

# 体验修复清单（2026-09-20）

状态：本批需求已完成源码实现和验证；安装包及 GitHub Release 尚未更新，不代表当前交付安装包已包含这些改动。

## 已修复

1. **输入快捷键统一**：普通对话、多论文讨论、阅读伴读共用输入器。Enter 发送，Ctrl+Enter 换行；兼容 Shift/Command 换行，IME 组合输入及候选确认不发送。生成中保留排队发送与停止。
2. **消息与等待状态**：用户/助手有独立角色标识、背景、边框和对齐；加入消息出现、思考圆环与等待点动画。状态跟随实际阶段和工具调用，支持思考、阅读文献、搜索网页、保存成果等；遵循减少动态效果设置。
3. **阅读伴读完整能力**：复用主聊天组件，具备模型选择、上下文/思考/图片能力提示、手动技能、附件上传、图片粘贴、队列、停止、回答复制和成果保存。论文预解析与划词翻译保留。
4. **所有对话共享行动工具**：新增 search_web、read_webpage、read_local_file、save_paper_note、save_research_idea、save_document。入口差异仅为初始论文背景；明确的保存请求可直接执行，无需切换页面。
5. **保存与恢复细节**：切换笔记页会刷新已保存笔记；历史伴读消息继续可读；旧会话加载失败时可重试或创建新伴读；选文可以取消而不退出论文背景。
6. **成果文件**：Markdown/TXT 保存到当前研究项目 exports 目录并返回下载地址；同名不同内容另存，重复笔记/灵感复用已有记录。各项目独立保存。

- 后端覆盖普通/单论文/多论文入口执行保存、持久化、下载、去重、网页解析与搜索降级、工具注册，以及研究项目之间的保存隔离。
- 隔离测试库的浏览器验证：Ctrl+Enter 换行、Enter 发送；文件上传和图片粘贴；模型调用收到图片和附件正文；直接工具保存灵感；读取论文全文；关闭后恢复历史；回答保存后笔记页立即可见；浅色/深色和窄屏布局。

## 辅助科研的任务验收

优先验证同一条连续任务：提出研究问题 → 找到并读懂关键论文 → 形成有来源的比较和研究笔记 → 用户调整方向 → agent 局部补查或改写 → 保存供后续研究复用。文献地图、比较表、笔记和章节草稿都可以是有价值的交付；用户无需等待整篇自动综述才开始工作。

记录人工主动操作时间、检查和修正时间、模型等待时间、重复阅读/复制操作及任务产物质量。与无 agent 的同等任务比较，同时观察是否把节省的阅读时间转成了更长的查错时间。尚未测得大幅节省，不给出虚构百分比。

自动继续是默认体验；用户可在需要时接管、追问和修改，协作不等于每一步强制确认。已实现的编辑、回查、版本与续跑能力应纳入此任务验收，而不是另建一套重复工作区。

换用“中文科研 RAG 幻觉评估”主题后的真实模型对照表明：low 在 37.59 秒保存笔记，但误归因实验分数；high 在 135.86 秒完成更多补读，修正部分细节，仍将需要受控解码的方法误判为普通文本 API 可用。两轮均未通过关键事实验收，不以保存成功或更高推理强度证明人工提效。详细根因和人工计时方案见 [辅助科研任务对照](research-assistance-evaluation.md)。

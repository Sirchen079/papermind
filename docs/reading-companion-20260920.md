# 划词翻译与 AI 伴读（源码功能，未重新打包）

- 打开内置 PDF 阅读器即后台准备全文；优先复用导入时的 full_text，缺失时使用本地 PyMuPDF 补解析并写回论文。PDF 显示不等待解析。
- 显示论文加载中／已加载／失败，可重试。同一数据库同一论文的同时打开合并为一个解析任务；请求结束不影响任务，线程使用独立数据库会话和原工作区上下文。
- 文件不存在、扫描件、加密文件及解析异常提供错误状态。扫描件仍需先 OCR，本功能没有增加 OCR 服务。
- 划选正文后可选择翻译（中文或英文）或问 AI。问 AI 在侧栏携带选文和当前 PDF 页码，不离开阅读器。
- 伴读复用现有 agent、论文全文工具、模型配置、停止、原问题重试及 ask_user 澄清。全文由模型按需要读取，不额外强制证据复核。
- 对话保存在后端；每篇论文的伴读会话关联、问题草稿、待发送选文在本机按资料库／工作区隔离保存。浏览器存储清空后，既有对话仍可在论文问答中找到。
- 默认只在用户点击翻译／发送问题时调用模型。后台准备全文不调用模型。翻译限 12000 字，伴读选文限 3900 字并提示缩小选区。
- 桌面并排阅读；窄屏使用可收起的侧栏，不遮挡阅读器顶部退出、翻页及侧栏开关。

前后端、Windows 文件版本及安装程序版本均为 0.6.10。前端 139 项测试通过，生产构建、PyInstaller 和 Inno Setup 编译成功，安装程序约 402 MB。保留既有分块大小提示。

构建产物连续两次真实 WebView2 启动、React 页面加载与正常退出均通过。随后使用 Inno 解包器直接提取最终安装程序，7992 个载荷文件与构建目录逐一比对 SHA-256，全部一致；从提取目录再连续启动两次，页面加载及退出均通过。此检查验证安装包载荷，不替代安装、升级或卸载流程测试。提取记录位于 `F:/论文管理/installer-extracted-0610`。

完整后端回归一次运行结束：1047 通过、1 跳过，耗时 1691.76 秒。保留 Starlette 的弃用提示及 Pydantic 的 ReadOnly 类型提示，共两个依赖警告。本轮完整回归无失败；没有用分项测试替换完整结果。前后端完整日志随交付提供。

## 冻结程序协作流程

对最终 PyInstaller 程序运行隔离测试，API 版本确认为 0.6.10。数据来自既有真实千篇库和模型对话的副本，仅复制流程需要的三份 PDF 与导出文档，关闭全部模型提供商。此次回放没有调用模型，不将界面成功记作新的模型质量验证。

- 已保存的两版文档刷新后可见，下载内容一致，旧稿文件保持不变。
- 人工编辑支持预览、重新编辑、关闭或刷新后的草稿恢复；模拟 503 保存失败后仍能保留修改并重试。
- 新对话能搜索人工修订稿、展开历史版本、下载及关联材料；刷新后关联材料和问题草稿均保留，可回到原对话。
- 后续消息可回查早期方法原文并打开 PDF 第 3 页；人工修订与保存文档保留第 14 页来源入口。
- 网页摘录显示实际正文、网址及读取时间；刷新、人工修订和已保存文档预览均保留原快照。
- 各流程未记录浏览器异常或模型调用；390px 界面无横向溢出。桌面文档预览、论文跳页、网页摘录和窄屏截图已经查看。

首次回放在下载旧笔记时出现 404，原因是测试副本只带入了网页资源笔记，未复制其数据库所引用的两个早期导出文件。补入原始测试目录中的对应文件后，在全新隔离目录完整重跑通过；未通过修改产品或忽略失败来使测试通过。两轮记录分别保留在 `F:/论文管理/research-reuse-frozen-0610` 和 `research-reuse-frozen-0610-v2`。

## 真实模型验证与质量边界

本版功能此前使用用户配置的智谱 Responses、GLM-5.3 完成实际调用：新对话查找人工修订稿并回读依据；按 PDF 页补读三篇论文；沿作者网址追查代码和现成权重；保存网页原文后在新对话离线回读。详见 [跨对话文档](saved-document-continuation.md)、[论文定位](paper-reading-navigation.md)、[资源追查](research-resource-reading.md) 和 [网页依据](web-source-snapshots.md)。这些分项文档中的“尚未打包”描述记录当时状态，当前交付范围以本发布记录为准。

网页保存与跨对话回读的两轮真实任务分别用时 21.83 秒、16.99 秒，合计 46178 tokens；第二轮没有重新访问网页。这是单次模型流程的耗时和使用量，不是研究者节省工时的测量。相关研究笔记仍有训练与部署条件混淆、将示例条件泛化、缺少依据的风险比较和成本遗漏；原始输出保留，未人工改好后冒充模型通过。没有把向量命中、流程完成或来源可回查等同于学术内容合格。

# PaperMind 0.6.10 研究成果复用候选版

本版把已保存文档、原文定位和网页依据接入同一科研协作流程。安装后在本机运行，无需另行部署服务器；允许使用联网模型 API，研究资料及记录保存在本机。

## 接着已有研究继续工作

1. 在论文对话中说明当前研究问题，要求 AI 找论文、比较条件或提出实验，而不必先生成整篇综述。
2. 让 AI 保存研究笔记；需要修订时，点击成果下的“编辑并保存新版本”。原稿保留，保存本身不调用模型。
3. 新建对话，点击输入框旁的“已保存文档”，按主题或文件名搜索、预览并加入当前对话。也可以直接让 agent 查找此前保存的笔记。人工版本有明确标识，可展开历史版本。
4. 核查论文依据时，打开来源中的 PDF 页码。Agent 也能直接按页读取，或从关键词在后文的命中位置补读方法与实验设置。
5. 涉及作者代码和现成权重时，允许 agent 沿作者网址补查。实际读取的网页正文会保存在来源记录中，展开“已保存的网页依据”可查看原文与读取时间。打开原网页查看的是当前站点；保存摘录保留当时内容。

网页来源随人工修订保留，并可通过已保存文档在新对话中回读。历史快照不要求重新联网；需要最新情况时仍可重新读取网页。删除原对话后，依赖其中记录的文档目录与来源也不再可查。本版不会自动补造旧版本没有保存的网页正文。

## 相对 0.6.9 的变化

- 跨对话查找、预览、下载和关联已保存的研究文档，并保留人工修订身份。
- 论文全文查找提供后文位置预览，支持按 PDF 页直接读取，降低反复停留在引言的概率。
- 网页提取优先主要内容和正文链接，其他链接可翻页，便于追查代码、模型和推理说明。
- 实际读取的网页片段保存在本地，可刷新回查、随文档修订沿用，并在新对话中读取。

## 使用范围

运行交付目录中的 `PaperMind-Setup-0.6.10.exe`。旧版 0.6.9 交付保持不变；新交付不含测试密钥、私有数据库或千篇测试论文库，连接在应用设置中配置。完整 Nature 与 Oh My Paper 资源继续随包提供。

真实模型测试已经完成查找旧稿、回读论文、追查作者资源和跨对话读取网页摘录，但仍出现模型角色混淆、条件概括过度等问题。来源可回查有助于研究者纠正结果，不代表所有建议已经正确，也没有测得整体节省工时比例。候选版的具体检查和未验证范围随交付目录中的发布验证记录提供。

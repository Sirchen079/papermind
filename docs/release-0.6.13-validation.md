## 最终程序与界面流程

Windows 文件版本和 API 版本均为 0.6.13。构建目录程序两次原生 WebView2 启动、React 挂载和正常退出通过。本机确定性模型服务另外验证首次注册 Nature、16K 上下文中的写作任务指导、保存成功后 HTTP 503 中断、重试沿用原任务且不重复保存。共 4 次本机模拟请求，零外部模型调用。

Computer Use 在最终程序提供的前端页面完成以下操作，测试配置中所有模型提供商均已禁用且移除凭据。

- 首页选择两篇测试论文并填写问题，进入对话后刷新，论文选择与问题草稿保留。
- 从首页最近工作打开研究成果，编辑 v1 后点击“保存并继续研究”。原稿保留，v2、原问题及两篇论文一起进入对话；刷新和离开后返回仍能恢复关联材料。
- 侧栏新研究创建独立空白对话，不携带上一次的论文、附件或问题。
- 在旧 FWI 对话打开原稿，从后续修订入口查看另一段对话中的人工稿，加入当前对话后刷新，修订稿引用仍保留。原有导出文件哈希不变。

浏览器无控制台错误，数据库另核对新旧成果内容、对话选材和零模型调用。界面交互是在内置浏览器完成，原生桌面启动由独立检查覆盖。本轮只检查默认 1280×720 深色界面；没有重复全量响应式、浅色模式和这些浏览器草稿的冷启动恢复检查。异步恢复期间一次即时可见性检查先返回未显示，等待对应附件后确认恢复成功，不计为产品缺陷。

在此窗口尺寸下，可选任务、技能、模型设置及附件占用较多对话高度，已列为后续产品体验改进。流程可用不等于界面体验已经完成打磨。

## 提取程序中的真实模型交接

使用从最终安装包提取的程序，复制此前隔离的 FWI 测试数据库，按实际成果交接接口创建新对话。材料为原综述与经 Codex 编辑的第 4 节 v1/v2，来源是此前保存的 HAL 摘要，不冒充用户本人修改或本次新读全文。指定 v2 后，真实 **glm-5.3 / Responses** 调用 `read_research_task` 读取该版本，完成关于下一步最小对照的回答。共 **2 次请求、18706 个应用记录 token、27.88 秒**，没有向量调用，也没有新增原文或联网来源读取。本项检验明确成果引用的交接，不是向量检索效果测试。

数据库和接口另确认原论文范围保留、附件引用持久保存、v1/v2 未被改写，新对话出现在首页最近工作中。本轮是自由研究接续；不把产品中注册了 Nature 或前述确定性任务路由通过，写成这次真实请求完整执行了 Nature 写作技能。

回答提出 L2/GSOT 与振幅处理的 2×2 组合，并列出共同条件，可作为讨论起点。但对照表有 A/B/C/D 四组，初始模型误差分档却只写 A–C；还将特定配置下的收敛表现过早归因于凸性。应先完整定义最小对照，并将经验收敛优势与需要独立依据的机制判断分开。没有执行数值实验，不据此判定整份计划已可直接实施。

内容核对只复用 Nature Writing 自检中适用的证据、公平比较和协议一致性要求，不是正式期刊审稿。模型原稿未被人工改写后重新记为通过，也没有重复调提示词直到出现满意答案。此次证明成果接续成功，科研内容仍需修订。

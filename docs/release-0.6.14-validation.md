1. 将原 GLM 回答（对话 8、消息 29）保存为 `研究回答-29.md`，自动进入现有编辑器。
2. 添加明确标识的 Codex 流程验收补记，保存新版本 `研究回答-29-cae6797f.md`。这条补记不代表研究者已认可内容，也不代表完成数值实验。
3. 关闭页面、终止并重新启动该隔离程序。新进程使用相同本地端口；重新打开对话后，原回答显示“查看已存文档”，可从原版找到后续修订并读到补记。
4. 创建独立新对话，从文档目录选择修订版并加入；刷新后附件仍明确指向消息 31 及该文件。

数据库和下载内容另核对：原回答全部字段不变，原有导出文件哈希不变，原稿与新稿同时存在，来源随新版本保留；保存和编辑没有模型调用。界面未出现控制台错误。默认 1280×720 窗口检查通过；390px 窄窗口可查看引用并操作提问区，页面宽度仍为 390px。没有重复全部主题及 PDF 伴读验收，相关源码基线见 [阅读空间记录](chat-reading-space.md)。

## 本版用途与范围

本轮把成果预览、agent 按需检索、公开全文接入、材料类型呈现及修订稿身份传递纳入桌面程序。用户可以保存回答、修改文档、重启后找回准确版本，再带着正文和来源进入新对话，减少复制正文、重新定位原文和反复解释修改的操作。

功能及真实测试依据见 [成果预览](artifact-reference-preview.md)、[按需检索](agent-directed-retrieval.md)、[大 PDF 接入](discovered-fulltext-continuation.md)、[材料呈现](research-material-presentation.md)及[版本上下文](revision-context-identity.md)。这些能力复用已有文档、来源、阅读器与技能体系，没有新增全局输出阻断或逐阶段审批。

## 实际界面与本机流程

在隔离的真实研究资料副本上，以构建后的程序提供界面服务，用浏览器操作验收。安装载荷一致性与提取程序原生启动另行验证，不把浏览器操作描述为安装向导或原生窗口全部交互验收。

1. 未配置模型时，把实际模型回答保存为文档，并在编辑器追加明确标为 Codex 验收用途的注记；生成文档 44、修订版本 45，原回答和原有导出文件保持不变。此注记不表示研究者认可实验方案。
2. 冷重启程序后，从旧稿找到后续修订；准确文件名为 `研究回答-43-89c3f92a.md`。保存的四项来源随版本保留。
3. 从保存的原文材料打开对应 PDF，第 14/29 页可读。
4. 在独立新对话中引用准确修订版本，刷新后关联仍在；预览显示正文、版本和来源，不显示模型内部指令。

冻结程序的确定性测试共两组，均使用本机模拟模型：4 次请求验证 Nature 首次注册、默认 16K 任务路由、工具后失败恢复、成功保存不重复及准确修订上下文；另 3 次请求验证从新对话回读修订正文和原来源。两组外部模型调用均为 0。它们检验产品机制，不评价科研推理能力。

## 真实模型结果与限制

本次源码改动后，使用用户配置的 GLM-5.3 对同一个 FWI 接续问题真实调用一次：17.72 秒，应用记录 16314 tokens；没有工具或向量调用。实际发给模型的上下文包含准确文件名、父版本、未采用状态及修订正文。模型没有再次建议 τ 趋近于零，也保留了若干已纠正的边界；但仍遗漏恒等排列与合成实验 τ=4，重新提出部分已有共同条件，并把独立 L2 实现说得过于确定。结果记为部分通过，原回答保留，未通过反复生成挑选结果。

这次普通接续没有加载 Nature；不能用此前技能加载记录替它作证。Nature 的任务入口实际加载机制由冻结程序的另一组路由测试覆盖，两者不混淆。

尚未完成真实研究者工时对照、同任务竞品比较、数值 FWI 实验或整份综述的全面质量验收。版本身份准确进入上下文只能消除应用丢失信息的原因，不能保证模型始终正确理解和完整保留信息。后续重点仍是研究者能否更省力地检查、纠正并继续使用成果。

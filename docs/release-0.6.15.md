# PaperMind 0.6.15 本地候选

本版贯通研究材料的获取、查看与接续。Windows 桌面运行，不需要部署服务器；允许联网检索和使用自配模型 API。

- 关联已存成果时直接预览正文、来源和版本，不再把模型内部提示当成预览正文。
- Agent 先理解问题和已有材料，再决定是否检索及如何查询，普通追问不再默认触发整库向量检索。
- 找到公开 PDF 后，可接入已有论文并沿用本地解析、索引、章节阅读和页码回查。已实测约 80 MB 的作者稿。
- 检索候选、摘要、原文片段和研究记录分别展示，保存稿与后续讨论保留实际来源。
- 修订稿的准确版本身份和已有采用状态进入后续上下文，普通追问与失败恢复使用同一机制。

从研究对话提出问题，按需加入论文或已保存文档；使用“文献综合”或“修订综述”任务直接接入对应 Nature 指导。原文可从材料中的页码打开；有用回答可保存为文档，编辑后继续讨论。普通草稿生成不需要逐阶段审批。

真实 GLM 测试验证了材料获取与接续，但仍会遗漏条件或给出依据不足的研究建议。研究者应通过回查、修改和讨论控制关键判断；本版不宣称自动综述完全正确，也尚未测得相对竞品的整体工时优势。

安装包最终核对记录随交付目录提供。功能验证见[材料呈现](research-material-presentation.md)和[版本接续](revision-context-identity.md)。现有许可及第三方声明不变。

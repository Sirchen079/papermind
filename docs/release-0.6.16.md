# PaperMind 0.6.16 本地候选

本版将已有研究成果的回读与长任务接续纳入桌面应用。无需部署服务器，资料保存在本机；可联网检索并调用自行配置的模型服务。安装包不含模型密钥和个人论文库。

## 从已有成果继续

- 阅读论文后，让 AI 保存论文笔记；阅读器内可查看、修改。之后在新对话中要求“使用这篇论文已有的笔记继续比较”，Agent 可以列出并完整读取笔记，再按需要回查原文。
- 文档详情及关联成果预览可展开“生成时的用户要求”，并返回原对话。它提供历史背景，当前要求和已保存修订仍优先。
- 文献写作可在对话的研究设置中选择“文献综合”或“修订综述”，直接加载内置 Nature Writing 的相应指导。自由研究中的技能发现仍由 Agent 按任务选择，不保证每轮都加载。
- 长任务连续读取多篇论文时，应用会在完整工具批次之间压缩较早上下文，保留原问题和最近批次。摘要不保证无损，关键判断仍可回查原文和保存成果。
- 保存工具的真实历史回执与文本说明分开传递；用量统计包括摘要调用。不增加逐阶段审批。

## 适用范围

本版适合文献阅读、比较、研究笔记积累和人工修订后的持续讨论。真实测试已发现模型仍会混淆实验条件、把测量配置泛化为实施要求，或作出过强解释。请利用原文和编辑功能核对关键科研决策。

已完成的读写、接续和桌面验证，与科学结论正确性分别记录。尚不能据此宣称千篇综合质量全面达标或已测得真实研究者工时优势。完整技能资源随包保留，资源存在不等于每轮已执行全部技能步骤。

实现与原始限制见 [论文笔记回用](paper-note-reuse.md)、[生成要求回查](document-generation-context.md)、[工具历史](research-tool-history.md)、[长任务接续](active-reading-compaction.md)和 [Nature 修订指导](nature-revision-evidence-routing.md)。最终交付目录另附发布验证说明、源码和校验清单；0.6.15 保留。

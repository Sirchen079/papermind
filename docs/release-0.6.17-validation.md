# 0.6.17 桌面候选验证

2026-09-27。本版将 Nature 精读卡原始脚本执行、报告留存及卡片到 PDF 的回查纳入桌面程序，也包含此前在源码完成的关联研究文档回查。用户无需部署服务器或单独安装 Python。

## 构建范围

复用原有 PyInstaller、原生桌面验证和 Inno Setup 流程。F 盘剩余约 300 MB，因此为构建脚本增加 `-OutputRoot`，将程序、中间文件及安装包写到 D 盘。没有移除旧交付或用户资料。

冻结了 377 个程序和构建源文件；相对 0.6.16 对应源码，25 个文件变化、5 个新增。版本更新包括前端、后端 API、包元数据和 Windows 版本资源。完整内置技能资源按已有目录清单逐文件核对，许可证与来源说明保留。

## 冻结程序的执行与恢复

新建隔离研究空间，导入此前 FWI 核查用的 L1 论文 PDF 和精读卡。以本机确定性模型驱动真实 Agent 工具循环，实际加载 paper-card 核心指导、执行原始 `prepare_paper.py` 与 `audit_paper_card.py`，再读回报告。

共 7 次本机模型请求，外部模型请求为 0。合格结构卡保留来源警告；不完整草稿的审计返回结构问题后仍完成回答，没有全局输出阻断。记录原始脚本哈希、输入快照和实际退出码。此项验证执行与保存机制，不评价模型选工具能力或科学内容质量。

通过打包程序生成整体备份，调用同一 EXE 的实际恢复命令到新目录，再启动恢复后的空间。三份报告逐字节一致；原卡片正文、PDF 以及保存的对话工具记录一致。测试使用构建程序；其与最终安装包载荷的一致性另行逐文件核对。

## 仍需验证的产品目标

来源整理不等于通读论文，结构检查通过不证明科学结论正确；自动图式清单仍可能遗漏。范围引用打开起始页，印刷页码和缺少论文身份的指针不猜测映射。原有研究文档回查保留实际输入关系，不代表所有输入均被最终成果采用。

原版单项目导出尚未扩展执行报告，完整记录请使用整体备份。本轮也没有真实研究者工时对照、竞品同任务比较或新增百篇综合质量验收。整体产品目标仍在推进。

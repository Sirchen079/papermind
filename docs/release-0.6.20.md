# PaperMind 0.6.20 本地候选

本版补齐从新论文进入资料库，到引用整理、研究稿找回和后续讨论的衔接。Windows 桌面运行，不需要另行部署服务器；允许连接用户配置的在线模型。

## 使用变化

让研究助手获取已知的公开 PDF 时，提供核对过的题名、DOI 或官方 arXiv PDF 链接。新记录可自动取得作者、年份及引用信息；已整理的记录保留原有元数据，书目信息暂时取不到也不影响可读 PDF 入库。

从 BibTeX/RIS 导入的卷、期、页码或文章编号会保留。在论文详情的“引文与元数据”中检查或修改，然后导出 BibTeX/RIS，或将论文复制到其他项目，仍可继续使用这些信息。

在研究对话中打开“已保存文档”，搜索已有研究稿。明确记录为尚未采用的核对稿与此前版本均可找回，作者和采用状态显示在列表、预览及后续版本中。“加入当前对话”把准确版本和同样的来源说明交给 AI；无需先采用草稿即可继续讨论。人工编辑并保存后，原有版本与来源仍能回查。

## 延续的能力

最多 1000 篇的专题任务、项目内检索和原文阅读、Nature 与 Oh My Paper 内置资源、精读笔记、研究稿修改和跨对话接续继续保留。完整技能资源已内置，不代表每次请求都会执行全部资源。

自动书目补齐目前用于新建的已知标识符公共 PDF 记录；普通拖入 PDF 和旧记录批量补齐不在本次范围内。过去已经丢失的卷期页码可编辑或重新导入完整引文修正。研究稿是可继续推敲的成果，不能替代论文原文。

原许可证未改变。实际构建、原生启动、旧库升级及流程验证范围见交付中的发布验证说明。

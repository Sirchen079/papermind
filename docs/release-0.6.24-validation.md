# 0.6.24 验证记录

2026-09-30，对照为已交付的 0.6.23。本轮只处理真实文献调研遇到的产品断点，复用默认模型选择器 `pick_llm`、已有 `index_local_paper` / `index_paper` 和公开下载服务。没有新增模型提示、论文专用规则或审批阶段。

## 问题与修复证据

0.6.23 冻结程序在隔离空库中复制已有加密模型配置后，真实英文查询 4.28 秒返回 5 篇候选，但关键词只有原句、`screened=false`、模型用量记录为 0。原因是调研使用独立用途模型选择器读取不存在的 `chat_model_config_id`，未沿用常规 `role_default=chat`。改用现有默认选择器后，中文主题“近两年全波形反演（FWI）目标函数与失配度量的新方法”36.41 秒返回 10 篇候选，包含两条英文扩展，每篇都有意见；实际调用 GLM-5.3-flash 两次，应用记录 2059 tokens。检索和筛选至此可用，不据此判断筛选意见全部正确。

真实 OpenAlex 记录 `W7139117513` 的 `best_oa_location.pdf_url=null`，只有 DOI 网页；旧程序将其标为 PDF。现按[官方位置字段](https://help.openalex.org/data/locations/)区分网页与直接 PDF，网页仍可回查、题录可以入库。两个真实工作 ID 的旧关联过滤式返回 400；按[官方 OR 语法](https://help.openalex.org/api/filtering/)改为一个字段下的多个值后返回 200，实际 `find_related_openalex` 取回 3 篇关联文献。

界面真实勾选并添加一篇公开 PDF 与一篇题录，PDF 的 16 页能从候选直接打开。但入库后索引数为 0，发现调研漏接既有索引服务。修复后，在另一空库重放同一批真实候选的导入阶段，没有重做模型筛选：9.23 秒完成两篇入库，BGE-M3 保存 47 个正文/题录片段及 1 个题录片段；按方法术语检索返回 5 个正文结果，来源包含 PDF 第 2–6 页。导入与查询合计 4 次 BGE-M3 调用、19636 应用记录 tokens，文本模型新增调用为 0。向量服务失败时保留本地索引，未配置向量模型也可按关键词查找；已有未索引条目补建索引，已索引条目不重复嵌入。

## 回归与边界

前三个缺陷的新增回归在修复前全部失败，索引缺陷的两个回归也先失败；修复后，相关后端分组 57 项与 32 项通过，去重收集为 60 个测试；前端 165 项通过。两组有重叠，不能相加当作不同测试。覆盖默认模型接续、网页/全文区分、多个关联 ID、PDF/题录/已有条目索引，以及向量服务失败时的本地检索。0.6.23 后端全量回归及其测试断言修正仍见上版记录，本轮不据定向通过宣称全量重新通过。

OpenAlex 搜索在本日已恢复；此前 503 加 Retry-After 只能证明当时请求暂不可用，不足以确定是本机 IP 风控。按[当前官方认证说明](https://help.openalex.org/api/authentication/)，基础查询可不用密钥，免费密钥可提高每日额度；不再把提供联系邮箱当成限流解除保证。单个来源仍可能无法下载，记录该篇状态供用户处理。

这是流程与工程验证，候选相关性、漏检率、书目精度、独立留出任务和真实人工净节省仍未系统评价。公开 PDF 含论文原文，测试数据库和已配置凭据仅存在私有验证目录，不进入交付。正式安装、升级和卸载向导仍需单独验证。

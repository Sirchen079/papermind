# PaperMind 0.6.24 本地候选

本版修复文献调研从“描述主题”到“入库后继续研究”的四个断点。调研现在沿用已配置的默认对话模型来扩展检索词、给出候选意见；网页入口不再被当成 PDF 下载地址；关联文献可一次查询多个 ID；入库后自动建立本地与向量索引，向量服务暂不可用时仍能按关键词查找。

研究者可以描述中文主题，查看每篇候选的摘要和 AI 意见，勾选需要的论文加入库内。公开 PDF 可直接阅读，没有直接 PDF 地址的候选先保存题录。已有未索引条目在重复添加时补建索引，已索引条目不重复调用向量模型。

真实测试已完成中文 FWI 主题调研，以及公开全文、题录入库和正文来源页码回查。AI 筛选仍是初步建议，检索覆盖面、科学判断与人工总工时尚未通过系统评价；研究者仍决定哪些候选有用。[验证详情](release-0.6.24-validation.md)。

安装包为 `PaperMind-Setup-0.6.24.exe`。无需自己部署服务器，可使用自己的联网模型 API。0.6.23 及以前交付保留；随包附源码、验证摘要和 SHA-256 清单，不包含测试库、私有论文或密钥。正式安装、升级、卸载向导尚未验证。

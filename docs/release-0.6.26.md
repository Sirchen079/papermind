# PaperMind 0.6.26 本地候选

本版接通论文原始 PDF 中的作者资源入口与 Agent 的网页阅读。整篇 OCR 偶尔漏掉代码、数据或模型脚注；现在 Agent 可读取原始超链接、PDF 页码及附近文本，再实际阅读作者项目页。正文继续使用全页 OCR，无需重新识别整篇，也不修改既有研究稿。[使用说明](pdf-resource-links.md)。

同时修复中文正文中裸网址的点击目标：引号、中文括号和后文留在正文，资源链接分别指向完整网址。直接使用已保存稿，原稿内容不被重写。

在对话中选定论文，要求“检查作者提供的代码和权重入口，核对资源页并保存笔记”，即可沿已有阅读、来源保存与成果流程使用。URL 是入口；当前可访问性、权重身份和任务适配仍以实际读取结果为准。自己的模型连接、key 和 OCR/向量用途仍按既有设置配置，无需部署服务器。

Self-RAG、CRAG、RAFT 三篇实战完成 54 页全部 OCR、308 个向量分块、比较稿保存以及界面局部纠正。原 AI 稿仍有研究判断错误，人工修改后各版本及来源可追溯。这验证连续工作流程，未证明独立科学质量、人工净节省或竞品优势。[任务与错误记录](ocr-research-comparison-validation.md)。

安装包为 `PaperMind-Setup-0.6.26.exe`；此前 0.6.25 交付保留。程序、源码与筛选后的验证摘要随包提供，个人资料库、原论文、密钥和模型连接留在用户本机。[本版验证范围](release-0.6.26-validation.md)。

# PaperMind 0.6.27 本地候选

本版让用户选定论文的完整入库正文在预算允许时直接进入研究对话，减少模型反复找章节和研究者搬运材料。仍使用现有论文库、全页OCR、全文工具、来源回查和成果修订；放不下的正文可继续按章节或原页读取。[使用说明](selected-paper-context.md)。

从论文库选论文，或在研究对话中选定几篇并提问即可使用。无需重建旧库，也不需要新服务器。精确摘录和已保存文稿继续保持其研究焦点，原稿和后续版本均可回查。

新材料的真实对照验证了完整供给、保存和修订链路，但本次总用量与等待增加，原AI稿仍有实验条件错误。更多材料不保证更正确或更省钱；本版不声称已证明科研净提效或竞品优势。原稿、逐项核对和调用记录保留。[验证范围](release-0.6.27-validation.md)。

候选安装包名为 `PaperMind-Setup-0.6.27.exe`，0.6.26及以前交付保留。个人资料库、论文原文、模型连接和密钥不随程序包交付。升级前可用已有整应用备份；正式安装、升级与卸载向导尚待实际验证。

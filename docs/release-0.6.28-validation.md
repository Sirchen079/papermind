# PaperMind 0.6.28 发布验证

日期：2026-10-01。本版补齐本地安装与关闭流程，减少首次安装时的权限要求，以及关闭应用、卸载和重装造成的研究中断。继续复用 Inno Setup 的安装模式、登记和卸载；桌面关闭问题对照实际使用的 CPython 3.12.10 实现处理，没有增加安装框架、依赖、数据库迁移或科研生成阶段。行为与复用依据见[安装与资料延续](installation-continuity.md)。

## 原始失败和修复证据

第一次真实桥接安装启动能打开 WebView2 与 React，但关闭时发生 `ConnectionResetError` / WinError 10054，随后本机服务等待退出超时；原日志保留，不能当作单纯的验证脚本失败。检查 CPython 的 Proactor 连接结束流程后，发现 `socket.shutdown()` 抛出重置会中断后续关闭与服务器解绑。修复仅适配桌面本机服务接受的 Socket，在最终 `SHUT_RDWR` 遇到连接重置时继续原传输层清理；出站连接、异步子进程和协议回调的其他错误不被掩盖。

初次单靠真实 TCP 重置未稳定复现；之后对标准库关闭调用注入同类重置，修复前相关用例失败、修复后通过。协议错误可见性和真实异步子进程另有验证。两类失败原日志、最终回归以及源程序/构建/解包/安装版的关闭日志均保留。没有通过修改检查器的成功条件抹掉实际关闭错误。

原先两次卸载虽然完成并保留资料，但最后检查两份日志中自定义保留分支的执行标记时失败。对照[Inno Setup 卸载事件](https://jrsoftware.org/ishelp/topic_scriptevents.htm)确认，旧脚本使用 `CurUninstallStep` 而非 `CurUninstallStepChanged`，卸载器不会调用该函数；静默保留资料的自定义日志和普通卸载的删除询问都未执行。这是产品缺陷，不是核验脚本的假阳性。修复事件名称后，仅重编译最终安装器，运行程序与其 832 份其他冻结源码保持；此前安装器、脚本指纹、日志和失败结果留存。本页结果表中的安装、升级、卸载、重装和再卸载以修复后安装器的新一轮实际检查为准；两次最终卸载日志都出现保留用户资料的执行标记，没有删除日志检查来绕过原失败。修复后运行载荷仍与此前 0.6.28 构建逐字一致，并从最终安装器再次完整解包核对。

安装向导曾分别尝试隐藏和可见窗口的只读自动化检查，均无法激活目标窗口，返回 `failed to activate captured window`；没有执行向导点击，已停止对应专用进程。因此本轮完整证据来自官方命令行安装流程和实际程序验证，不能声称人工点选向导已验收。失败窗口截图显示桌面背景，未当作产品截图分发。

首次卸载的核验脚本在原卸载进程返回后立刻检查自删除，触发一条断言；卸载工作进程随后正常删除自身和安装目录，日志确认完全卸载、无需重启。保留过早检查的失败记录，仅为核验脚本增加 20 秒上限的完成等待，继续核对原次卸载的剩余结果；没有重复卸载、手动删文件或改变产品代码。

重装核验曾错误预期 `/GROUP` 参数会产生自定义开始菜单文件夹，因此查找该文件夹失败。本项目隐藏该选择页，[Inno Setup 官方规则](https://jrsoftware.org/ishelp/topic_setup_disableprogramgrouppage.htm)是此时总是使用默认文件夹；实际在当前用户的 `PaperMind` 组生成两份快捷方式。保留错误假设的记录，按实际目录核对目标，继续原次重装检查，没有重复安装。初轮重装前仅检查了预期的自定义组，未冻结默认组的旧快捷方式，因此不声称初轮旧开始菜单文件逐字保全。最终一轮安装和重装均在文件复制前确认实际默认组不存在，避免复用既有快捷方式。

## 尚未证明的范围

本次没有修改真实机器上的全用户 0.6.22 安装，没有实测已经发布的全用户安装器升级到本版；当前用户升级起点是专用桥接安装，必须保留这一条件。没有实测管理员模式、人工点选资料删除、用户默认资料目录不存在时的历史资料迁移，或所有 Windows 环境。以上路径保留产品实现与官方依据，但不写成实际通过。

资料恢复使用完整真实库的隔离副本，API 只回读既有资料；没有调用外部文本或向量模型，未新增用量。原生产目录用于逐文件保全核对，没有启动该原库进行研究操作。打包仍包含内置科研资源；本轮没有执行 Nature 写作工作流，资源指纹通过不能写成已运行科研技能。

科研输出与竞品提效结论沿用此前[新材料阅读对照](release-0.6.27-validation.md)及[20 篇 40 问报告](heldout-reading-validation.md)的限定。本版没有重测科研内容：模型仍可能错读比较条件，更完整全文在此前单例中更慢、tokens 更多；没有独立研究者计时、净节省或同任务竞品优势证据。

# 0.6.11 发布验证记录

2026-09-26。本地候选版，核心是协助研究者阅读、核查、修改和继续使用研究材料。本记录区分程序可用性、模型内容质量和实际人工效率。

## 最终构建与安装包

前后端、API、Windows 文件版本及安装配置均为 0.6.11。最终安装程序 421,765,794 字节（约 402.23 MiB），SHA-256：`7f5b4f38bce70ff38a705174255798f9e78801caea437781c34b43deebc7b049`。

生产前端构建、PyInstaller 和 Inno Setup 完成。构建目录内连续两次原生 WebView2 启动、React 页面加载与正常退出通过。直接提取最终安装包，7996 个载荷文件与构建目录逐个 SHA-256 一致；从提取目录再连续启动两次原生桌面窗口，同样通过。没有执行日常环境的实际安装、升级或卸载。

350 个程序源文件与本次重建快照一致；972 个 Nature 与 Oh My Paper 原始资源与清单哈希一致。源码压缩包、凭据排除及交付文件的结果分别由随包的交付检查与 SHA256SUMS 记录；不会把测试数据库、论文库或凭据纳入分发。

## 测试范围和发现的缺陷

首次完整后端回归为 1059 通过、5 失败、1 跳过，耗时 1761.44 秒。五项失败均来自报告测试从当前工作目录定位模板，模板本身存在。并行复现还发现测试共用临时目录会清理其他测试进程仍在使用的数据库。已改为测试文件相对路径和各次运行独立目录；从仓库根目录和后端目录分别执行报告测试，各 7 项通过。

修正测试基础设施后的完整回归为 **1064 通过、1 跳过、2 项依赖警告，2363.58 秒**。这轮在后述连续采用修复前启动，属于完整基线，不表述为最后三处产品文件修改后的再次全量运行。

真实三篇比较随后产生四条局部建议，连续采用两条时，第二份版本没有包含第一处修改。原稿及各文件存在，但形成平行版本，用户需要手动合并。实际 API 和新增回归均复现失败。源码已修复：后续采用保留当前对话的既有修订，定位未改变的目标片段；目标已被改动时保留建议供用户回读调整。版本文件名也改为稳定基础名，避免持续追加后缀。

最终修复后的 **28 项相关回归全部通过，153.75 秒**，覆盖连续采用、重复原文的两种采用顺序、人工改写、目标冲突、重试、版本保留与跨对话发现。当前前端 **141 项全部通过**。最初失败日志和修复后的结果同时保留，未用后续成功覆盖原始失败记录。

## 最终程序的流程回放

下列检查直接运行重建后的可执行文件，使用隔离数据副本；界面回放关闭真实模型提供商：

- 四条真实模型建议：人工编辑其中一条，刷新恢复，再逐条采用并刷新核对。每一步等于累计的精确局部替换；最新文件包含全部四处修改，原稿和历史文件哈希保持不变，版本名称不继续增长。下载与文档目录内容一致。
- 单条修改建议：原文对照、用户修正、排版预览、模拟 503 后保留草稿并重试、采用状态恢复、网页依据沿用，均通过。
- 选段核查：键盘与鼠标选文、取消与文档切换、原问题和人工稿身份保留、刷新及失败恢复通过，不会自动发送。
- 既有科研协作：论文来源回查、PDF 第 3/14 页跳转、直接编辑、跨对话搜索与关联文档、网页快照沿用，均通过。
- 各界面回放没有浏览器异常或模型调用，390px 窄屏没有页面横向溢出。连续采用后的桌面和窄屏截图已查看。

章节工具另使用本机确定性模型桩：从聊天 API 到目录提取、方法和实验读取、来源保存均通过；目录没有被保存为正文证据，PDF 页码保留。共 3 次本机模拟请求、零外部模型调用，这是集成测试，不是模型质量测试。

## 真实模型与人工协作证据

本版相关的八组真实调用汇总为 41 次文本请求、628169 tokens，使用用户配置的智谱 Responses / GLM-5.3。实际记录见 [研究任务对照](../research-assistance-evaluation.md)、[章节阅读](../paper-section-reading.md)、[选段核查](../document-passage-check.md)、[建议采用](../document-edit-proposals.md) 和 [三篇比较与修订](../research-comparison-collaboration.md)。随包摘要不含原始请求正文或凭据，也不是全部历史用量或账单。

章节阅读的专项复测正确识别了先前遗漏的受控解码/API 限制。三篇比较提取了有用的研究分工和输入条件，审阅者指出疑点后，agent 回读定义并提出局部修正；用户可以直接改写建议后采用。但仍有过强的解释、次要页码和成本表述问题，不能将可回查来源或成功保存等同于整份回答正确。

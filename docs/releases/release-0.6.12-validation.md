## 安装载荷与真实接续

安装程序为 421764459 字节，SHA-256：`6c52edf796751fd3ed5ff475df7f31add92e43e71d2589c0a3737c6edf677a18`。从最终安装包直接提取的 7997 个载荷文件与构建目录逐个哈希一致；提取程序再连续两次原生桌面启动、React 挂载和退出通过。没有执行实际安装、升级或卸载。316 个程序与构建源文件在构建期间保持不变，972 个原始技能资源在源码与程序中均与清单一致。

从提取程序运行真实 glm-5.3 / Responses 接续，使用上一轮隔离数据库的副本，指定已经过 Codex 编辑的 FWI 修订稿。任务是准备三组 GSOT 振幅误差消融实验计划。首次请求已加载文献综合与 Nature Review 指导，模型随后读取准确的修订版本及 3 份保存来源快照，识别其中一份 arXiv 内容与主题无关，并保存实验计划。全程 5 次模型响应、83871 个应用记录 token，86.95 秒；没有重新联网检索或调用向量模型。与之前的修订任务内容不同，不作耗时提效百分比对比。

计划提出了目标函数、振幅处理和误差类型三个比较方向，保留待检验标签，可以继续讨论。但仍有需纠正的机制推断：不能把振幅缩放只线性改变距离当作既定前提；“逐道归一化对 AVO 无效”的说法需结合具体归一化与权重定义更正。应区分距离中的尺度、道间权重和数据预处理，并补齐对照及指标定义。原文 §2.3 明确讨论尺度与 AVO 权重（[原论文](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2020JB021504)）。这些内容核对来自本次 Codex 审阅，不冒充原 Agent 新读到的全文。

原始计划作为模型草稿保留，没有用人工修改后的正文覆盖为成功结果，也没有执行数值 FWI 实验。此次证明的是最终程序能沿修订成果和已保存来源继续形成研究材料；不证明实验计划已可直接执行、整体科学质量通过或实际研究者已经省时。完整运行与核对记录在 `F:/论文管理/release-0.6.12-20260926`，交付目录附不含凭据的摘要。

## 产品边界

本候选旨在让研究者能持续使用和修正材料。技能实际加载、模型成功返回和文档成功保存均不能替代专业内容核对。此前 FWI 修订明确包含 Codex 的补查和编辑，不作为用户本人采用或模型自主纠错的证据。

没有完成实际研究者的主动操作、核查与纠错工时对照，也没有同任务竞品盲测。没有执行用户日常安装环境的安装、升级、卸载；不自动替换旧版或发布到外部平台，许可证沿用原状。

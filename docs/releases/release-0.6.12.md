# PaperMind 0.6.12 本地候选版

本版围绕“带着材料解决研究问题，再沿用成果继续研究”，把任务选择、Nature 写作指导和失败后的接续纳入桌面程序。安装后由应用自行运行本机组件，不需要用户部署服务器；可正常联网检索并使用自选模型 API。

## 从任务开始

在论文问答输入框上方选择本轮任务：

- **自由研究**：阅读、比较、讨论与其他研究工作；需要时可手动指定技能。
- **文献综合**：围绕研究问题综合已有资料，直接采用 Nature Writing 的 Review 指导。
- **修订综述**：带入已有研究稿，说明要修改的问题和范围，采用 Nature 的局部修订指导。指导适用于研究草稿，不要求正式投稿格式。

任务选择随当前对话草稿保存。用户已有明确要求优先；技能被停用或材料不足时仍可继续完成可做的内容。模型可以读取完整内置资源，没有新增全局输出审批。

## 一条可继续使用的研究流程

1. 在项目中导入论文，或从“已保存文档”把研究笔记加入对话。
2. 选择任务，提出具体问题，例如比较不同目标函数对噪声、振幅误差与实际数据的适应性。
3. 让 Agent 保存笔记、比较表或草稿；从来源入口回查重要判断。
4. 指出需要纠正的段落，查看局部建议；可直接编辑建议，再采用为新版本。
5. 原稿及其他段落保留，新版本可以再次作为对话材料，继续补查或设计实验。

核查、编辑和采用由研究需要决定，不是每个回答都必须经过的固定流程。采用修改本身不再次调用模型。

## 本轮改进

Crossref/OpenAlex 资料以可读摘要和元数据展示，避免反复翻阅无关 API 字段；仍注明实际读到的材料范围。模型请求在已完成工具调用后失败时，可沿保存进度继续，成功保存的成果不会被恢复逻辑自动再写一次。远程模型的生成等待按推理强度调整。

Nature 与 Oh My Paper 仍完整内置，共 55 个入口、972 个原始资源；外部脚本与服务的执行取决于实际环境和配置。资料、文档版本与来源保存在本机，向云端模型发送材料时会使用所配置的服务。

## 当前验证边界

真实 FWI 任务使用用户配置的 glm-5.3 Responses 服务，生成了指定章节的修改建议，并完成编辑采用、原稿保留与后续材料关联。原始建议仍存在专业表述问题，采用稿包含 Codex 的补查与修改。任务入口和技能加载不保证科学结论正确。

本版不宣称已经证明研究者节省时间或整体优于竞品；这些仍需同任务比较。最终可执行文件与安装载荷的核对范围以交付目录的发布验证说明为准。许可证沿用原状，本地候选不自动替换日常安装，也不自动发布到外部平台。

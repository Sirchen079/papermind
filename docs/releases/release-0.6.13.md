# PaperMind 0.6.13 本地候选版

本版把“提出问题、找到已有成果、修订后继续研究”接成桌面内的连续流程。Windows 安装后直接运行，无需自行部署服务器；可使用已配置的联网模型 API 或本机模型。

## 从一个研究问题开始

1. 在研究主页写下问题，可顺手选择最近导入的论文，再点击“进入研究对话”。问题与选材一起带入；未选论文时在当前项目库中按需查找。
2. 补充要求后发送，继续比较、追问、回查来源或保存研究稿。侧栏“新研究”开启独立对话；“研究对话”可找回已有讨论。
3. 需要逐篇整理一批论文时，从首页“专题综述”或侧栏“论文整理”进入。批量任务仍保留材料范围、阶段草稿和暂停续跑。

## 从已有成果继续

- 首页显示本项目最近的研究对话、论文整理、专题综述和知识页；运行中、待回答工作优先，点击回到原记录。
- 在少量论文整理页点击“与 AI 继续研究”。修改尚未保存时，使用“保存并继续研究”，带上明确的成果版本、原有论文选择及保存来源。
- 打开旧对话里的文档，点击“查看文档与修订”，可发现其他对话中的后续人工稿，选好后带入当前讨论。不同修订分支分别保留。
- 刷新后问题草稿和关联材料仍可恢复；原稿、历史版本和来源继续保留。模型失败时可从已保存工作接续。

## 使用范围

研究者仍负责重要学术判断。模型可以读取原文和已纠正的稿件继续工作，但一次接续成功不表示新推断全部正确。此前真实 FWI 测试中，模型仍出现扩展任务范围及实验条件不充分的问题；可以局部修改并继续，不必重做整篇综述。

已有千篇库、百篇材料处理、完整 Nature 与 Oh My Paper 资源和用户自选模型能力继续保留。材料数量、技能数量和成功生成字数不作为研究质量或人工效率的证明。

## 安装与数据

使用 `PaperMind-Setup-0.6.13.exe` 安装。原有数据目录与模型设置保持既有路径；升级前可在设置中创建整应用备份。安装包不含测试论文、测试对话或模型凭据。当前许可保持 GPL-3.0，第三方组件归属见随包声明。

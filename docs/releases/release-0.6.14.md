# PaperMind 0.6.14 本地候选版

本版让研究对话更易阅读，并补齐“有用回答 → 留成文档 → 人工修改 → 继续研究”的操作。Windows 安装后直接运行，无需自行部署服务器；联网检索和用户配置的模型 API 仍可使用。

## 从回答留下研究成果

1. 在一条回答下方点击“保存为文档”。正文和已有来源在本机保存，随后打开编辑器，不调用模型。
2. 可直接关闭，或修改后点击“保存新版本”。原回答、原稿及来源保留；保存记录仍标明内容来自 AI 回答。
3. 原回答下方会变成“查看已存文档”。从这里查看原稿和后续修订，也可下载 Markdown。
4. 在另一段对话打开“已保存文档”，找到所需版本并“加入当前对话”，输入下一步问题。选定的成果引用可在刷新后恢复；有新要求时无需复制整篇正文或重复整理来源。

保存和编辑本身可以在未配置模型时完成。发送新的研究问题仍使用已配置模型；文章和来源的真实性、实验条件以及重要学术判断需要研究者检查。

## 阅读与提问

任务、技能和模型选项收在“研究设置”中；当前任务与模型摘要保留，已选择的技能及额外复核也会显示。论文范围可展开检查，关联材料可点击预览。PDF 伴读复用相同布局。

既有主页最近工作、少量论文成果交接、专题综述、全文阅读、来源回查、局部修改建议及失败接续继续保留。需要完整综述时仍可从专题入口处理明确选择的一批论文；日常讨论可以从任何有用的阶段成果继续。

## 安装与数据

运行 `PaperMind-Setup-0.6.14.exe`。数据目录与模型设置沿用既有路径；升级前可在设置中创建整应用备份。安装包不包含测试论文、测试对话或模型凭据。当前 GPL-3.0 及第三方声明保持原样，原 0.6.13 交付保留。

具体测试范围和限制见 [发布验证记录](release-0.6.14-validation.md)。本版补齐的是已观察到的操作断点，尚未证明总体科研效率或同任务竞品优势。

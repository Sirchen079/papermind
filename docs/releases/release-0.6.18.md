# PaperMind 0.6.18 本地候选

本版围绕已有综述的持续使用：保留人工修改，加入新论文后只更新相关段落，并让研究者直接核对修改与原文。

- 在研究工作区继续已有综述。材料未变化时原样保留当前正文和版本；新增材料复用旧分析。
- 展开“查看修改对照”，选择保存版本，查看修改前后、AI 修改说明和当时保存的原文。未保存历史快照的旧版本会明确说明来源入口使用当前材料。
- 点击“继续修改这一段”进入原有编辑器；保存新版本后，历史记录继续保留。已变化的历史段落从“按段修改”选择当前正文。
- 修复共用高推理模型进行文献重排时输出预算不足的问题。

这些功能不增加强制审批，不要求部署服务器。允许联网检索和使用自己配置的模型 API；查看修改对照和手工编辑不调用模型。现有 Nature 与 Oh My Paper 资源和来源许可说明继续保留。

真实百篇样本追加一篇后，原分析全部复用；两次 GLM 写作完成 9 处替换，17/26 原正文段落逐字保留。此为单次样本结果，不能换算为千篇综合质量保证。模型仍可能重复引用、泛化方法差异，研究者需核对关键判断。

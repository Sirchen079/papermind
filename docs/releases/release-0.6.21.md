# PaperMind 0.6.21 本地候选

本版修复选定少量论文后，正文检索在大模型重排前每篇最多只留下三个片段的问题。候选数现在按所选论文数分配既有预算，使同一篇论文后面的实验表格也有机会进入重排。全库检索仍保留原有的论文多样性分配。

使用方法：在论文库选定材料进入研究对话，要求助手检索相关证据并按需补读正文；回答中的来源可打开对应 PDF 页，保存的研究稿可编辑或带到下一次讨论。修复不需要重建已有向量索引，也不增加逐阶段审批。

本版复用现有混合检索、大模型重排、正文阅读、Nature Writing、来源保存与版本接续。真实 GLM-5.3 与 BGE-M3 测试完成了检索、补读和保存；测试原稿仍有比较遗漏和适用条件泛化，核对稿单独保存且标为 Codex 修订、尚未采用。没有据此宣称自动综述合格或人工提效已经证明。

Windows 安装包为 `PaperMind-Setup-0.6.21.exe`，无需自行部署服务器，允许使用自己的联网模型 API。包内不含测试数据库、API 密钥或论文资料。安装包载荷解包与桌面启动验证见[发布验证](release-0.6.21-validation.md)；实际安装向导、升级及卸载尚未验证。原 0.6.20 交付保留。

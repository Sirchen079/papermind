# PaperMind 0.6.22 本地候选

本版让聊天记录中的文档作者身份与文档卡片一致。Codex核对稿会显示“Codex 修订稿 · 尚未采用”，AI回答存档会显示为存档，研究者自己编辑和采用的版本仍显示为“你”。保存稿的原文、来源和版本关系不变。

继续保留0.6.21对选定论文检索候选的修复。选中论文后，可让助手检索相关原文、按需补读、保存研究笔记，并从出处打开PDF页。模型判断仍需研究者核查；这次更新没有变更模型提示或加入输出拦截。

安装包为 `PaperMind-Setup-0.6.22.exe`，无需自行部署服务器，允许使用自己的联网模型API。随包附源码、验证记录和校验清单；测试数据库、论文资料与密钥不在交付包内。实际安装、升级、卸载向导尚未验证。[验证详情](release-0.6.22-validation.md)。

# 0.6.23 验证记录

2026-09-29。对照基线为[0.6.22交付](release-0.6.22-validation.md)。本版新增文献调研板、外部工具只读查询接口与技能文件、可选高级解析引擎接入、研究对话 OpenAlex 工具；未改动 0.6.22 的作者身份标注、检索候选与综述流程。借鉴 [PaperSpark](../paperspark-reference.md)（CC BY-NC 4.0，仅设计参考）与 [InstSci](../literature-survey.md)（MIT，仅设计参考）的思路，未复制任何外部代码。

新功能测试：后端定向回归 21 项（外部查询接口、OpenAlex 工具、高级解析协议与失败路径、文献调研管线/批量上限/重复检测/删除）全部通过；前端类型检查与单元测试 165 项全部通过。模型质量沿用的仍是 0.6.21 真实 GLM-5.3/BGE-M3 研究证据，**本版不重做模型测试，聊天提示新增的 OpenAlex 工具句不在该证据覆盖内**。

冻结程序实机验证：真实 0.6.22 大库副本（1006 篇、503 MB）由 0.6.23 冻结程序完成升级迁移 `f0830c1d3002 → b4e8f2a6c9d1`，文献调研两张新表建立、1006 篇论文与用量记录全保留；外部查询接口在该库上报告 1006 篇已索引，混合检索"全波形反演 目标函数"命中正文片段，无令牌请求 403、非法参数 422；高级解析引擎未配置地址时拒绝并给出中文指引、非法 URL 拒绝、配置后可提交并可取消；文献调研任务创建、轮询、终态、删除全链路可用。浏览器打开冻结程序核对界面：侧栏"文献调研"入口与表单（空查询禁用、有内容启用、纯空格禁用）、OpenAlex 风控说明文案、设置页"高级解析引擎地址（可选）"字段均在，无控制台错误；截图因主机高负载渲染超时未取得，以可复核的 DOM/ARIA 快照为证据。

真实 OpenAlex 检索在验证当日因本机 IP 触发搜索端点限流（`search=` 与 `title_and_abstract.search` 均 503 + `Retry-After`，非搜索查询正常）未能完成端到端召回验证；调研任务按设计先有界等待重试、仍失败则以可读错误结束且不产生候选。**真实检索质量与 OA 下载导入待限流解除后由首次真实使用补记**，建议配置 `openalex_mailto` 进入礼貌池。

验证中发现并定位一个环境现象（非本版缺陷，0.6.22 起即存在）：启动时 `PRAGMA quick_check` 对大库做全库完整性检查，503 MB 库在冷缓存与高 I/O 负载下实测 262 秒（热缓存 0.7 秒），期间界面表现为"启动慢"。当日回归套件与打包并行执行放大了该效应；对大盘用户首次冷启动的耗时影响值得后续优化（如增量检查或跳过策略），本版未改动该行为。

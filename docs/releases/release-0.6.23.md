# PaperMind 0.6.23 本地候选

本版新增四项围绕“文献从发现到入库”的能力，0.6.22 及之前的论文阅读、专题综述、作者身份标注全部保留。

**文献调研板**：描述主题（如“近两年关于 FWI 目标函数的论文”），AI 扩展检索词并从公开 OpenAlex 接口收集候选，逐篇给出摘要与初步意见；你过目勾选后一键加入论文库。检索只走官方公开接口、不经图书馆账号；下载只用开放获取链接，逐篇串行、每批至多 10 篇，避免触发来源方风控。没有公开全文的候选先入库题录，之后可手动补 PDF。

**外部 AI 工具查询**：程序启动后在数据目录写入 `agent_access.json` 供本机其他 AI 工具（Claude Code、Codex、ZCode 等）发现服务；配套只读接口 `/api/agent/summary` 与 `/api/agent/search`，凭本机令牌访问，外部工具与内置助手看到同一个论文库。随包附技能文件 `skills/papermind-library/SKILL.md`，复制进所用工具的技能目录即可使用。

**高级解析引擎（可选）**：设置中可填写本地或云端版面解析服务的 http(s) 地址；文档转换新增“高级解析引擎”模式，整册交给外部服务处理扫描件与复杂表格，逐页结果回填、来源页码回查不受影响。留空则完全不启用，页面图像仍由本机保留。协议说明见[高级解析引擎](../advanced-parse-providers.md)。

**研究对话新增 OpenAlex 工具**：助手可检索本地库之外的公开学术文献、核实书目信息、追溯相关工作（`search_openalex` / `find_related_openalex`），拿到开放获取 PDF 链接后可直接入库精读。

安装包为 `PaperMind-Setup-0.6.23.exe`，无需自行部署服务器，允许使用自己的联网模型 API。随包附源码、验证记录和校验清单；测试数据库、论文资料与密钥不在交付包内。实际安装、升级、卸载向导尚未验证。[验证详情](release-0.6.23-validation.md)。

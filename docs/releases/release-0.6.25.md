# PaperMind 0.6.25 本地候选

本版把新 PDF 的默认路径接成「全页 OCR → 本机 Markdown → AI 阅读与检索索引」。论文库上传、文献调研和公开 PDF 获取共用这条流程，不再把原生提取的零碎正文提前作为最终阅读内容。

使用自己的模型连接，在「设置 → 文档与检索」选择 OCR 和向量模型，再导入论文。未配置 OCR 时先保存 PDF 并等待配置；配置后自动继续。论文详情显示转换进度，完成后点击「Markdown 原文」阅读、核查原页或下载。关闭面板不影响任务，重启可继续未完成的导入，旧库不会自动重识别。[完整说明](../pdf-markdown-ingestion.md)。

已用用户指定的硅基流动 DeepSeek-OCR 实测中英文两篇全文，共 30 页，生成 Markdown 与 139 个向量分块，并验证正文检索与页码回查。补验界面上传的 1 页只调用 OCR 和向量模型，没有误用 OCR 生成摘要。1006 篇旧库副本迁移后资料保持一致。[验证范围](release-0.6.25-validation.md)。

原页对照发现 OCR 会错读个别合并表头和数值；关键科学结论仍需核查原页。流程连通不等于论文识别准确率或研究提效已通过系统评价。

安装包为 `PaperMind-Setup-0.6.25.exe`，随包附源码、许可证、验证摘要和指纹清单。交付不包含测试库、用户密钥或个人连接配置；各用户自行配置自己的 key 和模型。此前 0.6.24 交付保留。正式安装、升级、卸载向导尚未验证。

# PaperMind 0.6.28 本地候选

本版补齐安装与关闭流程：首次默认当前用户安装，既有安装沿用原模式；静默安装拒绝盘符根目录，静默卸载保留资料。WebView2 关闭连接时的 Windows 重置不会再中断本机服务的最终连接清理。详细行为见[安装与资料延续](../installation-continuity.md)。

沿用 0.6.27 的论文正文供给、来源导航、保存稿和修订延续能力，前端与研究生成策略未调整。完整正文仍可能增加模型用量；已有研究验证中的实验条件错误没有被本版安装与关闭修复解决。

程序包含本机服务和运行依赖，使用者不需要部署服务器。资料与安装目录分开，联网检索及用户配置的模型 API 可继续使用。本版核验记录保留实际安装器、库副本、原安装与原资料的检查结果；不把部署流程连通算作竞品优势或科研质量通过。

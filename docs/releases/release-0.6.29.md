# PaperMind 0.6.29 本地候选

本版将正在阅读的 PDF 原页直接带入 AI 伴读，减少截图、存图和上传操作。打开论文阅读器，翻到需要核对的物理页，点击“带入第 N 页原图”，再补充问题并选择支持图片的模型发送。已有问题、材料与会话继续使用；带入本身不调用模型。

原页作为图片快照保存，重复同页去重，翻页与刷新后保留。附件可以展开查看并打开当前 PDF 的相应页；发送失败的重试使用原快照，当前 PDF 后来改变也不会改写历史图片。每轮沿用四附件上限，读取失败或仅文本模型会显示相应提示。详见[原页伴读](../original-page-companion.md)。

功能复用原有 PDF 渲染、图片附件和本地草稿机制，默认 OCR、Markdown、索引与科研技能继续沿用已有实现，没有新增机器学习依赖或数据库迁移。安装、关闭及资料恢复沿用[安装与资料延续](../installation-continuity.md)。程序自带本机运行依赖，使用者不需要部署服务器；联网检索和已配置模型 API 仍可使用。

原页图片有助于查看表头、分组、单位和脚注；它不是经过验证的表格网格或科学结论。现成解析器诊断仍有条件合并和漏表反例，不能通过打开原图就认定问题已解决。源码与打包验证不等于真实视觉模型准确性、独立研究者工时或竞品优势验收。最终检查范围与证据见[发布验证](release-0.6.29-validation.md)。

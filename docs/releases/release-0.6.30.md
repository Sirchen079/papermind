# PaperMind 0.6.30 本地候选

本版交付阶段审查修复批次（卡 01–24）：文献地图与精读卡片全流程可用性、引文核对的可信度、导出文件安全，以及思考等级的统一控制。已生成的论文库、综述稿与阅读进度继续沿用；两个新增数据表（精读卡片、文献地图）的迁移已改为幂等，升级安装不会因旧库已有表而失败。

**核对标签更可信。** "已核对原文"现在要求引文与原文逐字一致且数字对得上：模糊命中时数字改为对照原文命中区间（模型把 48.1 改写成 58.1 不再蒙混过关）；不足 12 个字符的短引文一律不算命中；"52.7" 不会再命中原文里的 "1952.7"；带单位数字（52.7ms、12dB）正确解析；近似命中单独显示"近似核对原文"并保存相似度。存量卡片会在下次生成地图时按新规则免费重新核对，不消耗模型调用。

**地图与卡片更稳。** 模型输出额度一次给足（约上下文窗口一半），不再因推理占用导致卡片降级为只有元数据；单批归类、单主题综合出错不再拖垮整张地图，完成后会汇总"N 篇卡片未生成、N 篇未能归类"等提示，可点击继续补齐；模型连续调用失败时明确中止并提示检查模型设置，而不是静默显示"已生成"。

**导出文件可直接发给导师。** Excel/CSV 中以 =、+、-、@ 开头的文本不再被 Excel 当作公式执行（前置英文单引号，普通文字与数字不受影响）；PDF 提取文本中的非法控制字符不再导致 xlsx/docx 导出失败。Word、HTML、BibTeX 输出保持原有格式。

**思考等级一律由用户选择。** 设置页和对话页"配置模型"里选的等级现在对全部调用路径生效（包括此前被忽略的流式对话）；未设置时默认 high，兼容基准为 glm-5.3（max）。low、medium 仍是可选项，但不为其做专门优化。额度与超时按生效等级自动放宽（如综述在 max 档等待上限 1800 秒）。未设置等级的模型，已有综述的缓存会在下次运行时重新整理，属预期行为。

没有新增第三方依赖，也没有改对话提示词。安装、关闭及资料恢复沿用[安装与资料延续](../installation-continuity.md)；程序自带本机运行依赖，使用者不需要部署服务器，联网检索和已配置模型 API 仍可使用。本版说明先于实际安装验证交付；核对规则收紧后旧卡片重核、缓存重新整理与导出净化的实际效果见后续发布验证记录。

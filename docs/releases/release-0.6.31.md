## 本轮修复与用户影响

- **导入身份更谨慎（R01，fc89391；第二轮 W01，2b4dcf7）**：PDF 参考文献节内的题名、DOI/arXiv 编号不再被当作本篇身份证据——题名核验只对照参考文献节之前的正文，节内出现的被引题名不再自证身份；正文中的单个被引编号同样必须通过题名核验，不因「唯一候选」免检。元数据与正文冲突、证据不足或查询失败（超时、异常、无结果）时，一律按「未确认」处理：候选标识被扣留，不参与自动归并、不写入记录，新文档保存为独立条目并标注「未确认」；不覆盖其他论文的题名、编号与原文关联。明确属于同一论文的重复上传仍按既有契约去重并保留原 PDF。
- **卡片核验信息看得见（R02，b335237）**：精读卡片页与导出保留字段级核验结果——数字与原文不符、缺失数字、来源页码（全文/摘要定位）以中文警告显示；引文未核验时不再包装成「已核验」；整卡完成与字段核对分开显示，问题不阻断浏览或导出。
- **技能包并发不丢目录（R03，6fea949）**：技能包导入、更新、删除的目录变更串行化；两个包并发导入成功后均可用、可读，不再互相覆盖丢失目录项。
- **APA 引用对应（R04，cd739a4；第二轮 W03，299e813；第三轮 S04 按规范收紧，见下）**：选择 APA 后，正文文内引用按作者—年份与参考列表共用同一套作者、年份、消歧映射，不再出现无对应条目的编号。年份字母 a/b 仅用于同一作者组同年的不同作品；同年缩写碰撞（如两组同年均缩写为「Smith et al.」）按 APA 展开足够多的后续作者姓氏消歧，不再误加年份字母。参考文献节之后章节（如附录）中的引用同样参与编号与书目收集（GB/T 顺延编号、APA 作者—年份），代码围栏内的字面编号不改写、不收集；导出不写回数据库原稿。GB/T 7714 数字制行为不变。
- **导出只换文献节（R05，ef3a268；第二轮 W02，93cd6f0；第三轮 S02 收紧围栏规则，见下）**：导出替换「引用文献」节本身，其后的附录、讨论等章节保留；章节扫描按统一围栏规则识别代码围栏（开、闭最多 3 个前导空格缩进，tab 不计为空格；闭合须同字符且长度不小于开启，4 空格伪闭合保留在围栏内；含四反引号外层围栏内嵌三反引号、字面量标题）与合法缩进标题（≤3 空格缩进，4 空格以上是代码块），长围栏代码块与缩进标题不再导致后续内容丢失；代码块中的同名标题不被误认成文献节。该规则只覆盖围栏开闭与缩进标题，不声称完整 CommonMark 支持，缩进代码块、行内代码等未覆盖语法不在承诺范围。无文献节时的追加规则保持确定、不重复。
- **构建保证（R06，54030b6）**：打包时 MCP 相关资源收集改用当前 PyInstaller 官方 helpers；关键收集失败直接令构建失败，不再打印后跳过；新增检查防止 helper 失效复发。
- **批量操作后视图刷新（R07，59fa9d2；第二轮 W04，5b50a51）**：批量补全书目、获取公开全文后，当前列表与已打开详情自动刷新；共享加载状态由「仍是最新序号的请求」负责结束——批量刷新与搜索交错、过期响应或失败路径都不再遗留永久 loading，导入等功能按钮随之恢复；保留搜索、筛选、已加载范围与选择；刷新失败与业务结果分开提示，不引导重复执行已成功的操作。
- **技能资源面板同步（R08，84725c9）**：技能包导入、更新、删除后，资源面板立即反映新目录与新内容；删除已选包后入口与内容消失，无残留下载入口；慢请求下旧响应不写回。
- R09（11320aa）、R10（c202dc6）为测试修复（隔离夹具、异步受理/完成/失败契约），不改变用户可见行为；未删除、跳过或放宽既有断言，PDF 原文库外路径保护保持拒绝。
- **第三轮返工（S01–S04，修复提交 621c8f7，基于 1b778e4）**：
  - **S01 正文题名误归并**：正文或参考文献节提及被引题名不再放行归并——无 metadata 题名时，仅当检索题名为首页首个非空内容行起最多 4 行连续非空行的完整标题前缀才视为自身声明；页眉等复杂布局识别不了时按「未确认」独立保存。归并判定只由实际查询成功的标识来源驱动；确认后仅采用该查询记录自身携带的标识，其他候选编号不随行写库、不参与去重。
  - **S02/S03 围栏规则与引用收集**：围栏开、闭共用同一条规则（见 R05 条目）；代码围栏内的引用编号不改写、也不收集进书目，仅出现在代码中的编号不占首现号、不进书目。
  - **S04 APA 消歧收紧**：et al. 至少替代两名作者，只剩一名未列作者时列全；同姓不同人的作者组跨年份同样在首作者处加名首字母；展开消歧只用于同年缩写碰撞；年份字母 a/b 仅用于同一完整作者组同年多篇。

## 已知限制与未验证项

- **安装与数据位置**：安装器（Inno Setup，PrivilegesRequired=lowest）首次默认安装到当前用户 Programs 目录，既有安装沿用原权限模式；安装记录写入相应 HKCU/HKLM 卸载键。CloseApplications=force 会关闭需替换的运行实例；旧安装目录数据迁移目标为 `%LOCALAPPDATA%\PaperMind\data`。本次不在开发者真实安装环境试装；最终隔离安装、升级和资料保留验收结果随 GitHub 发布页提供。历史 `build/installer_output/` 中返工前旧包不得用于发布。
- **身份核验边界（第三轮 S01 收紧后）**：题名核验不以全文出现放行——无 metadata 题名时，仅当检索题名为首页首个非空内容行起最多 4 行连续非空行的完整前缀才视为自身声明；题名上方有页眉/running head、作者行插入等复杂布局识别不了时，一律按「未确认」独立保存（安全侧降级，代价是部分带页眉 PDF 无法自动归并）。归并判定只由实际查询成功的标识来源驱动；metadata 来源免核验仅指查询成功的那个标识来自元数据，其余候选编号一律不发布、不随行写库。参考文献节内出现的题名一律不作为身份证据。
- **APA 消歧边界（第三轮 S04 后）**：数据中完全无法区分的作者组（同名同姓且无任何身份差，如两条「张三」）文内形式可能重合——年份字母按完整作者组身份分组，不再为不同作者组提供 a/b 兜底；首字母/全名限定仅作用于首作者；CJK 或单词名无名可取时退全名，仍相同则保持原形。列表条目作者仍为全组全列、不加缩写限定。
- 真实模型输出与科研内容准确性未验收；独立第三方复核未完成。
- 发布验收未覆盖或迁移开发者本机真实安装；公开发布状态以对应 GitHub Release 为准。

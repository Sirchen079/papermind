0.6.31 候选在本轮返工前经审查发现文献身份、证据展示、导出结果与发布验证缺口，不适合直接发布。以下为修复内容与剩余边界。

## 本轮修复与用户影响

- **导入身份更谨慎（R01，fc89391）**：PDF 参考文献部分出现的 DOI/arXiv 编号不再被当作本篇身份去自动归并已有记录；元数据与正文冲突、证据薄弱或查询失败时，新文档保存为独立条目并标注「未确认」，不覆盖其他论文的题名、编号与原文关联。明确属于同一论文的重复上传仍按既有契约去重并保留原 PDF。
- **卡片核验信息看得见（R02，b335237）**：精读卡片页与导出保留字段级核验结果——数字与原文不符、缺失数字、来源页码（全文/摘要定位）以中文警告显示；引文未核验时不再包装成「已核验」；整卡完成与字段核对分开显示，问题不阻断浏览或导出。
- **技能包并发不丢目录（R03，6fea949）**：技能包导入、更新、删除的目录变更串行化；两个包并发导入成功后均可用、可读，不再互相覆盖丢失目录项。
- **APA 引用对应（R04，cd739a4）**：选择 APA 后，正文文内引用按作者—年份与参考列表共用同一套作者、年份、消歧映射，同作者同年后缀一致，不再出现无对应条目的编号；GB/T 7714 数字制行为不变，数据库原稿不被改写。
- **导出只换文献节（R05，ef3a268）**：导出仅替换「引用文献」节本身，其后的附录、讨论等章节逐字保留；代码块中的同名标题不再被误认成文献节；无文献节时的追加规则保持确定、不重复。
- **构建保证（R06，54030b6）**：打包时 MCP 相关资源收集改用当前 PyInstaller 官方 helpers；关键收集失败直接令构建失败，不再打印后跳过；新增检查防止 helper 失效复发。
- **批量操作后视图刷新（R07，59fa9d2）**：批量补全书目、获取公开全文后，当前列表与已打开详情自动刷新；保留搜索、筛选、已加载范围与选择；刷新失败与业务结果分开提示，不引导重复执行已成功的操作。
- **技能资源面板同步（R08，84725c9）**：技能包导入、更新、删除后，资源面板立即反映新目录与新内容；删除已选包后入口与内容消失，无残留下载入口；慢请求下旧响应不写回。
- R09（11320aa）、R10（c202dc6）为测试修复（隔离夹具、异步受理/完成/失败契约），不改变用户可见行为；未删除、跳过或放宽既有断言，PDF 原文库外路径保护保持拒绝。

# PaperMind 0.6.34

发布日期：2026-10-30。Windows x64 安装包、便携版与源码见[发布页](https://github.com/Sirchen079/papermind/releases/tag/v0.6.34)。

## 图书馆下载环境与获取入口

先在设置的“图书馆下载环境”中安装独立 Python、下载引擎和浏览器。设置显示安装阶段、失败原因和重试；所有研究空间共用环境。安装中可以离开设置，返回后继续查看；应用退出导致的中断可重试。

环境就绪后，在论文库选择题录，点击带图标、边框和环境状态的“通过图书馆获取全文”。环境未就绪时前后端均阻止启动，按钮旁提供“去设置安装”。获取任务不再隐式安装依赖。

使用本人机构账号在浏览器完成学校登录或验证。自动路线失败后可在同一浏览器会话中继续操作；支持从 PDF 查看器取回正文。已下载的正文也可上传到原任务，经过格式和论文身份校验后接回题录。环境准备失败、引擎未返回结果及登录等待分别显示。

环境安装需要联网访问 GitHub、Python 包服务及浏览器下载源；网络或 TLS 错误会在设置显示。实际获取范围由本人机构订阅权限决定。

## 删除论文与文献调研

每张论文卡片直接提供删除按钮，操作前确认。从库中移除后，该论文退出检索和图谱，历史引用记录保留。

文献调研先按 OpenAlex 外部来源目录准入，默认仅纳入 JUFO 2/3、挪威期刊目录 2 或 CCF A 收录来源，随后由文本模型筛选主题相关性。逐篇显示目录依据，关闭 AI 仍执行来源门槛。旧调研中未经来源评估以及模型建议略过的候选默认隐藏，可主动展开查看。候选不足时少返回。

## 工作台与阅读

本次公开发布同时包含 0.6.33 本地版本：石墨蓝、青柠与薄荷色工业研究工作台，主题与论文联动图谱及可暂停反馈，书架/清单视图，逐字段精读卡片修订和历史回查，原文阅读后的任务、位置与草稿恢复。支持日间和夜间主题及窄屏布局。

## 升级与验证

沿用既有 AppId、安装目录识别和资料保留机制。安装包、便携包及源码的 SHA-256 随 `SHA256SUMS.txt` 提供；本次构建、桌面启动、安装/升级/卸载的实际结果见发布资产中的 `release-validation.md`、`frozen-validation.json` 和 `installer-acceptance.json`。

自动安装与获取的状态流已通过隔离回归；本机访问 GitHub 下载引擎时复现过 TLS 连接失败。真实机构登录和论文获取成功率未作本版覆盖率验收。

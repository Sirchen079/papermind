# 辅助科研任务：新主题与推理强度对照

2026-09-26。目标是减少研究者筛选、阅读、比较、设计实验和修订的工作，不以自动完成整篇综述作为唯一成功标准。本轮只做诊断与验收记录，没有新增输出拦截、改变用户模型设置或重新打包安装程序。

## 任务与条件

从同一个真实千篇论文库的空白对话出发，寻找三篇用于中文科研 RAG 回答幻觉评估的论文，比较证据需求、额外生成、训练与推理权限、输出粒度及指标，并保存一页左右的实验准备笔记。用户约束是普通文本 API、无模型内部状态、暂不训练、允许现成小模型。未给模型指定论文、正确答案或核查结论。

先冻结评价条件，再运行 GLM-5.3 low；保留失败结果后，用相同输入和同一初始数据库的独立副本运行 high。通过既有 Responses 通道调用真实服务，未改变原数据库或原始密钥文件。两轮均由 agent 自行选择关键词搜索，没有触发向量和重排调用。不能把本轮称作向量检索准确率测试。

## 原文核查

low 选择 RAGTruth、RAGHalu 和 Think Twice Before Trusting。它完成了选文、提议人工标注与保存，但有以下实质错误：

- 将 RAGTruth 的 52.7 归给 GPT-4 prompt 基线。原文 PDF 第 7 页表 6 的整体 span F1：GPT-4-turbo 是 28.3，微调 Llama-2-13B 是 52.7。它只收到第 8 页一段缺少完整主语的导航预览，没有继续读表。
- 将 RAGTruth 的四类标注改写为包含“与常识冲突”。实际分类在 PDF 第 3 页，是明显/细微冲突、明显/细微引入无依据信息；方法正文没有读到就填入了细节。
- 将不训练直接推导为只能用 prompt 基线，没有检查现成检测器可用性；将候选答案反思迁移到自由文本科研回答，却没有交代候选空间和证据核对方式。
- 方案混合真实和人工扰动样本，却未分开报告；不同粒度方法共用 span 指标而无输出映射。API 用量缺少输入长度依据，不能按“成本可控”据此开工。

high 选择 RAGTruth、RAGHalu 和 SELF-FAMILIARITY。它对 RAGTruth 多次向后补读，正确报告了上述分数与四类标注，也明确指出中文效果未知。但仍有决定性错误：

- 把 SELF-FAMILIARITY 写成“无需 logits，普通文本 API 直接可用”。该文 PDF 第 5 页 §3.2.2 使用 constrained beam search 和响应概率；第 7 页明确因需要控制解码而未考虑仅提供 API 的模型。它对这篇只取了前部正文与导航预览，没有补读决定适用性的具体步骤。
- 将 NLI 的 neutral 同时映射为无依据和 NO-INFO，丢失了 RAGHalu 单独判断可验证性的第一层；这只能是另一个待测基线，不能视为忠实的零训练复现。
- 自行给出中文 F1 区间、上线阈值及 10–50 元费用，缺少试测或任务容错成本依据；将逐概念方法估算为每条一次调用，遗漏了组成步骤。

原文入口：[RAGTruth](https://aclanthology.org/2024.acl-long.585/)、[RAGHalu](https://aclanthology.org/2024.emnlp-industry.2/)、[Think Twice Before Trusting](https://aclanthology.org/2024.findings-emnlp.693/)。SELF-FAMILIARITY 的核查使用库内 P413 完整 PDF 提取原文，作者实现入口为 [Self-evaluation](https://github.com/soap117/Self-evaluation)。本轮没有执行这些检测方法或验证其实现。

## 对产品的含义

问题不只是模型大小或检索排名。原文工具可达、内容有页码、甚至更高推理强度，都不保证 agent 会读到决定可行性的步骤。当前主要失败链是：标题与引言形成路线判断 → 用短预览补细节 → 未读方法条件仍写成确定结论。higher effort 增加了部分补读，但没有消除这条失败链。

后续优先改进的是围绕研究决定的阅读与协作：把“采用哪条路线、需要哪些资源、如何比较”的关键依据读完整，保留可直接回查的位置；缺失处继续查找或作为待试的设想保留。并不要求每句话经过另一套模型审批，也不因一个未知条件拒绝交付整份笔记。

已有选段核查、原文回查、建议采用和版本沿用能降低纠错的操作负担，但尚未证明能抵消查错时间。Nature 等 skill 的完整内置可以提供写作规范，不能代替对具体方法和实验表的阅读。

## 人工效率如何验收

按任务而不是文档长度计量：选出合适基线、回答一个方法问题、形成比较表、修订一段论证、准备可执行试验，都可以是独立成果。先以一次 20–30 分钟规模的研究准备任务作试点，不强制整篇成稿。

采用相近难度但不同材料的成对任务，交替分配纯人工和 agent 辅助；避免让同一人先读熟材料再比较。记录检索阅读、操作、核查、纠错的主动时间，另记模型等待时间。产物由同一标准评估：关键研究决定、出处、适用条件、可继续执行性。重大错误未改正的结果不算提速成功；研究者主动改正所花时间也必须计入。仍需实际研究者执行，不能用 Codex 的审计时间冒充用户研究。

本轮原始记录在工作区外的 `hallucination-research-live-20260926` 和 `hallucination-research-high-20260926`：冻结条件、问题、逐次请求和响应、工具记录、笔记、usage 与核查结果。数据库、语料和凭据不进入分发包；两份原始笔记均保留，不覆盖为“修正后的成功结果”。

## 后续：方法已读到仍可能判断错误

2026-09-27 的[长文献路线实测](research-route-evaluation.md)中，模型实际读取方法章节并加载 Nature，仍误归纳表格、资源条件和实验阈值。后续评价因此区分未检索到、未读到和读到后误解；修订后的新会话交接通过，但不把它计作独立科学质量通过。优先按同一材料测试阅读范围，记录真实核查负担，不继续堆专题输出限制。

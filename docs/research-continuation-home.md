# 从首页接续研究

2026-09-26。下方保留开发阶段的验证记录；该功能随后纳入 [0.6.13 桌面候选](release-0.6.13-validation.md)，原 0.6.12 交付不变。

## 用户任务与断点

研究者隔一段时间回到项目，需要找回上次的判断、材料和成果。原首页只取最新一个 ResearchTask，再加载完整研究详情；从对话形成的文档、专题综述和知识页不会出现在“接着上次的发现”。已有成果需要分别进入功能页查找。

此次将该区域接入当前项目最近的五项工作，覆盖研究对话、少量论文研究、专题综述和知识页。正在运行或等待回答的工作优先，同一对话只显示一次。点击回到原记录，不另起对话，不自动运行模型。成果、来源、已采用修订和已有草稿继续由原页面管理。它减少找回研究上下文的导航操作；不改变模型写作质量，也没有测得人工总时间的节省比例。

## 复用与边界

- 复用项目数据库、现有活动目录、页面深链和文档版本，不增加任务表或独立工作区。
- 对照 [Pi 会话说明](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sessions.md)：按工作目录保存和恢复会话、提供已有会话选择器。这里适配为按研究项目恢复多种已有记录，只借鉴使用方式，没有复制上游代码。
- 全局“项目任务”继续按每次对话记录产生动态；首页按对话去重，二者不混用。专题综述的运行和完成状态也纳入全局活动。
- 新接口 `/api/w/{workspace}/research/recent-work` 只查询该项目的标题、状态、时间和路由；不加载论文全文、完整对话、来源快照或稿件内容。首页每 15 秒更新一次，刷新失败保留最后一次成功列表并提供重试。
- 最新消息决定对话是否等待回答或运行中；旧的待答卡片不会覆盖后续消息。手工修订消息和知识页直接编辑也可进入最近工作。草稿可恢复，空白对话和归档知识页不占位置。
- 只列最近五项；更早记录继续从原功能页访问。这次没有增加跨类型搜索和自动提炼任务标题。

## 验证

后端 11 项测试通过，覆盖项目隔离、同 ID 跨项目、长对话去重、手工修订排序、等待/失败/运行状态、旧运行任务优先、草稿恢复、手工知识页和归档状态、专题综述动态及原有对话动态键。前端 141 项现有测试和生产构建通过。

隔离 UI 数据副本来自此前的真实 FWI 对话与导出文档；另外加入明确标注“界面验证”的综述、研究草稿和知识页。副本移除了提供商凭据并禁用了模型，未消耗 API。界面验证记录保存在工作区外层 `home-continuation-20260926`，不进入安装包。

已通过：首页进入 FWI 对话 6，显示原关联修订稿与 `fwi_gsot_ablation_plan.md`；首页进入暂停的综述，刷新仍保留对应 ID、正文和继续入口；新建并切换到空项目后无其他项目记录，切回恢复原入口；手工知识页打开已采用版本；深浅主题默认窗口检查通过。

该数据副本连续十次本机请求返回 1407 字节，耗时中位数 6.5 毫秒。这只是本机元数据请求测量，不能推导为所有项目规模或机器的性能保证。`tokenusage` 与副本来源记录数相同，本轮没有外部模型调用。

停止隔离后端后，首页显示“暂时无法刷新，以下为上次加载的记录”，五个研究入口仍在。后端恢复后，自动刷新清除了错误并恢复最新列表；手动重试按钮在点击前已因自动恢复消失，因此不将此次点击记作手动重试通过。未给网络故障增加阻断研究内容的全局弹窗。

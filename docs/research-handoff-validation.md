# 已有研究成果交给 agent 继续工作的验证

2026-09-26。核心目标是减少重复交代背景、复制材料和重新整理，不要求用户等待整篇自动写作完成。

## 当前实现

- 专题页面增加“与 AI 继续研究”，建立独立对话。输入框给出可编辑的问题，关联专题以可预览、可移除的文字附件携带；不会自动发送付费请求。
- agent 的 `read_review` 可读取当前工作区里的专题范围、已保存正文、章节和逐篇分析；支持千篇目录分页、标题筛选和长正文连续阅读。
- 未完成的任务也能读取已有章节；如果用户已经编辑保存全文，读取正文时优先使用该版本。工具不暂停、不重启、不修改原专题。
- 生成分析与原文证据分开，`read_review` 的内容不自动登记为论文原文引用；需要具体事实时仍可调用已有全文阅读工具。

## 阶段成果交付与连续对话（0.6.8 候选）

新的真实实验保存了每次响应的普通正文及工具调用，确认此前的潜在缺口实际发生。记录为 `F:/论文管理/research-handoff-output-audit-20260926`：智谱 Responses、`glm-5.3-flash`，约 82 秒、6 次对话请求。聊天累计 68382 tokens；包含正文检索所用的 BGE-M3 和大模型重排后，新记账总量为 70331 tokens（embedding 33，rerank_llm 1916）。这不是账单金额，也不能把与前次随机运行的差异解释为确定的提速比例。

当前源码修复整个交付过程：

- 只将模型普通正文发送为阶段记录，实时保存到本地；不展示私有推理或原始工具上下文。

- 现有调用上限续跑保留完整工具上下文；仅有阶段记录的普通失败仍标为“重试”，不伪装成可以原地续跑，也不自动再次执行操作。

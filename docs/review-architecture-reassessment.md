# 综述能力与架构重新评估

2026-09-26。用户要求先回答能力边界、达到质量的方法和模型分工，再继续实现。本文是设计判断，不代表新架构已经实现或通过验收。暂停新增写作流程改动；已有测试保留作基线。

后续目标澄清优先于下文的自动成稿设想：用户明确以 AI agent 辅助科研、显著减少人工工作量为核心，不强求完全自动写完论文或综述。主动阅读的意义首先是帮助研究者查证、比较和持续推进研究；整篇自动成稿是可选使用方式。不能让自动成稿的完美程度阻塞有价值的研究笔记、证据比较和人机共同修改，也不能借此忽略事实错误造成的返工。

## 能力判断

目标是能够交付事实可靠、覆盖合理、具有跨论文综合和清晰论证的完整综述。不能用引用编号合法、生成成功、检索命中率或短问答表现替代这个目标。可发表性还涉及选题贡献、领域判断与期刊要求，不能由一次自动生成保证。

公开证据显示能力具备但稳定性依赖系统。OpenScholar 在跨论文长回答上显示检索、反馈和引用归属机制的作用，同时作者明确不声称完全自动化文献综合；这些结果不等于完整长篇综述已经解决。[Nature, 2026](https://www.nature.com/articles/s41586-025-10072-4)。SurveyGen 的完整综述评测指出，全自动生成仍有引用质量和批判性分析不足。[EMNLP, 2025](https://aclanthology.org/2025.emnlp-main.136/)。PaperQA2 在检索、综合和矛盾识别上的结果支持采用可操作原文的模型系统，但不证明任意领域无人干预的整篇综述达标。[原论文](https://arxiv.org/abs/2409.13740)。

## 当前已观察到的结构问题

1. `reviews/service.py` 逐篇分析、分组综合和全篇规划主要传递生成文本；摘要压缩的条件与不确定性会继续传播。
2. 章节按宽泛主题检索，选择固定数量摘录；写作使用分析卡，但对应具体断言的原文未必进入上下文。`requests/009.json` 的 P38 分析同时有确定归因和“仅假设”的矛盾措辞；原文补查不含 ELI5/oracle/TruthfulQA，章节使用了较强归因。
3. 写作 `ask()` 只接受一次打包材料，没有在形成具体论点时继续读取原文的接口。末尾修订仍依赖再选一批摘录，无法从结构上确保补齐。
4. 已有检索测试主要证明候选论文与片段能找到，不证明正文比较正确或覆盖主要路线。提示词改动容易围绕已知错误过拟合。

这些证据支持“证据传递与工作方式存在缺陷”的判断。尚不能证明所有错误都来自这一个原因，也不能未经对照就宣称工具调用能解决质量问题。

## 分工原则

- 模型负责问题拆解、研究路线分类、比较、综合解释、写作和修改；允许有依据的新推断，不把它限制成摘录拼接器。
- 本地系统负责原文及图表、精确定位、文献标识、数字计算、版本、持久记忆和调用记录。生成摘要用于导航，不能取代原始事实来源。
- 向量模型负责语义候选，配合词法和书目检索；参数量不是唯一质量尺度。最终论点的支持关系由阅读与比较处理。
- 最强可用文本模型投入核心阅读、综合、关键比较和写作；轻量模型承担可复核的分类与查询辅助。性能差异通过任务实测确定。
- 研究者控制问题、取舍和最终学术判断；日常生成不因缺少人工确认而停住。

## 拟采用的工作方式

全库建立可回溯的目录和研究地图；按研究问题组织证据，模型可以查论文、搜原文、读章节、看表格及图像。分组归纳保留原文入口和比较条件，写作过程中允许返回原文并调整提纲。正文形成后分别检查事实支持与综合质量，发现局部问题就修复局部，保留可用全文。

证据记录至少可表达：论点、来源位置、实验条件、结果、作者解释或系统推断。字段不齐不作为拒绝生成条件，也不需要为千篇论文预建庞大知识图谱。Nature skill 用于综述组织、比较与表达，不能代替资料阅读。

用户选择 100 篇时应对全部材料建立范围记录；1000 篇库支持不意味着每次将千篇全文放进一个上下文。按问题分配精读深度，保留未读、已筛选、已引用的区别，避免悄悄把整库综述变成少数热门论文的摘要。

## 验证优先于全面重构

同一批资料、模型和写作要求对比：现有摘要链、直接原文材料、允许主动阅读的写作。先在可人工核对的完整小专题验证，再扩大到百篇；同时记录调用量、时间、使用的原文和失败位置。相同预算比较效率，质量优先设置另列，不把更多花费带来的变化全归因于架构。

质量维度：关键事实和引用支持、主要路线与反例覆盖、条件对齐的比较、跨论文解释、全篇逻辑和可修改性。使用未参与提示词调试的材料与问题，不能只回测当前四个错误案例；模型自评分只辅助定位，不能作为合格证明。

主动阅读探针 `F:/论文管理/review-active-reading-probe-20260926.py` 已在隔离副本启动。它只能检验一章的一个机制假设，不是本方案的充分验证，也不是生产实现。后续评测转向连续辅助科研任务中的成果可用性、人工操作与修正时间，保留事实和引用检查，不将所有研发资源投入无人参与整篇生成。

# 已有综述的局部更新

## 用户任务与取舍

研究者已经修改过一份综述，加入论文后应当继续使用这份稿件。此前虽然将当前稿传入最后修订，但仍先生成另一份提纲和全部章节，再要求模型重写全文。百篇实测耗时约 44.4 分钟，只有 7/24 个输入正文段落逐字保留，增加了重新阅读和核查的范围。

本次把“首次成稿”和“沿已有正文更新”分开。新增论文仍先分析；旧分析按真实输入指纹复用。随后将当前正文及新增材料交给写作模型，由模型选择必要修改，程序按准确位置应用，保留其他正文和版本历史。研究者继续使用原来的更新、编辑、来源回查及历史入口。

## 更新行为

- 材料未变：保持当前正文和版本，不新增写作调用；旧检查点可同时补齐材料状态。
- 有新增或改变的材料：只分析变化论文，沿当前正文返回带段落位置的替换或追加；首次写作的提纲和章节不再重新生成。
- 当前正文过长：完整分组传入，模型只操作本组段落。未选中的段落由程序原样保留。
- 少量修改不可用：有效修改继续应用；无效建议及原因保留在写作说明，不阻断整份成果，后续仍能重试变化材料。
- 首次成稿中断：未被人工修改时继续原有断点；研究者已编辑其部分稿时，以人工版本为起点。

不要求逐段批准，也不保证模型提出的每处修改科学正确。模型负责选择、综合与表述，研究者决定是否采用研究判断；程序负责保存正文、版本及来源，并避免无关段落被整篇替换。

## 科研质量与下一步

本轮通过的是增量流程、精准保存及关键人工纠正保持，科学质量仍为部分通过。模型将 RaFe 与 SeRTS 的区别概括成“改为训练改写器”，但 SeRTS 本身已包含查询生成模型的 PPO 训练；也将可能的反馈误差传递写成确定结果。另需区分已报告的反馈构造耗时与尚不能跨文对齐的端到端成本。原文、模型稿、9 处修改对照、4 处局部核对记录和 v6 均保留；Codex 核对不冒充真实研究者采用或整篇科学结论验收。

新增论文内容在多个段落重复出现，说明目前的分组更新仍需更好的全篇协调。下一步优先让研究者在现有编辑流程中直接查看本次改动、来源及原版本，再将已验证改动纳入桌面候选；不为这篇样本增加专用提示词、硬性修改数量上限或全局审批。真实研究者核查时间和同任务竞品比较仍待验证。

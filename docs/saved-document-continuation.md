# 跨对话复用研究成果

2026-09-26，0.6.9 之后的未发布源码。原先聊天保存的 Markdown 文档只能在原对话中找到；已有论文笔记检索不包含这些成果，新对话缺少明确的发现入口。

现在输入框旁的“已保存文档”可按文件名、对话标题和正文关键词查找当前研究空间内仍保留在对话中的文档，支持预览、下载、回查来源以及返回原对话。默认排除被明确的人工修订关系替代的版本，可勾选查看；没有明确继承关系的 AI 新文件不会被猜测为同一版本链。搜索采用本机关键词匹配，不调用向量或文本模型；这不是跨语义文档检索的准确率声明。

“加入当前对话”保存所选版本的关联记录，agent 按当前问题决定读取哪些正文和来源；不把全部历史文档预先送给模型。关联材料和问题草稿刷新后保留。原始文件、人工版本和完整旧对话继续保留，加入材料不自动发送问题或生成新稿。

Agent 可调用 `search_saved_documents` 查找成果，使用 `read_saved_document` 分段读取。正文明确标注人工修订或 AI 保存，来源另列目录；只有真正读取某条来源原文，才会把该片段作为论文来源加入当前回答。读取的是当时保存的快照，论文被删除后不再把旧摘录加入新的来源，但研究稿仍可读取。接口基于当前项目数据库，跨项目隔离；不扫描任意本机目录。目录依赖保留的对话记录，删除原对话后该文档不再出现在此目录中。

## 真实模型验证

从已完成手工修订的真实三篇比较对话复制隔离数据库，新建一个空白对话，没有复制原对话历史、正文或论文选择。用户问题要求找到此前人工修订的 FLARE、DRAGIN、SlimPLM 比较笔记，并据此简述 RJ/QR 训练数据。

使用用户配置的智谱 Responses、`glm-5.3`、low 思考和 BGE-M3。模型主动执行 `search_saved_documents`，随后用 `read_saved_document` 读取 `retrieval-control-comparison-v2-a7e29306.md`（记录 13，人工修订稿），最后输出结果。正确保留 RJ 的三个数据集各 5000、筛选和降采样，以及 QR 的五个数据集各 1000 和 GPT-4 辅助标注。没有重新生成整份比较，也没有把这一过程冒充模型自主纠正原始错误。

端到端 16.23 秒，3 次文本调用、2 次工具调用，新增记账 23648 tokens（chat 23586，embedding 62）。模型多写了一段修订稿中的关联提示，没有在这次调用回读论文原文；这次证明新对话可发现并使用人工成果，不构成独立事实复核，也不能从一个例子推出整体人工时间节省。与同一长对话追问的输入不同，不直接比较两者成本比例。

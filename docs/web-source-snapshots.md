# 网页依据本地留存与跨对话复用

2026-09-26，未发布源码。接续[研究资源追查](research-resource-reading.md)：论文摘录此前已经保存在对话中，网页工具的实际返回正文却没有进入同等的来源记录，后续研究往往只剩网址和模型结论。

现在每次成功读取网页的实际文本片段、原网址、读取时间和原始字符位置保存在当前研究空间的对话来源 JSON 中，无需新增数据库表。网页搜索结果和未打开的链接不记作已读来源；空返回也不生成摘录。不同读取版本可以并存，不使用当前网站内容替换旧依据。这是实际读取文本的快照，不是整个网站、完整 HTML、所有链接目标或附件的离线归档。

对话与“已保存文档”预览显示“已保存的网页依据”，可展开查看文本、读取时间以及原网页入口。刷新后保留；人工编辑文档会沿用对应来源。网页与论文来源分开返回，网页不会伪装成论文编号，也不会进入论文捕获操作。

同一对话的后续问题按现有上下文预算沿用完整摘录；放不下时保留目录和回读入口。`read_chat_sources` 可在当前对话中离线回读；跨对话可先找到保存文档，再用 `read_saved_document(part=source)` 读取其网页依据。回读保留原来的读取时间和片段位置，不触发网络请求，材料明确标为历史快照。需要最新情况时仍由 agent 调用 `read_webpage`。可选证据复核也能收到真实网页摘录，但没有默认开启额外复核。

## 真实模型测试

隔离复制千篇数据库，使用用户已配置的智谱 Responses、GLM-5.3、low。第一对话要求阅读作者 CompAct 仓库并保存简短资源笔记；第二个全新对话只提供文件名，要求找到笔记并回读已保存网页依据，不重新联网。人工预先标准没有送入模型上下文。

- 第一对话调用 `read_webpage` 和 `save_document`，21.83 秒；网页摘录与 `compact-resource-note.md` 同时持久保存。
- 新对话调用 `search_saved_documents`、`read_saved_document` 正文，再读取 `part=source`，16.99 秒；没有调用网页搜索或网页读取，返回正确的模型标识，并区分推理示例与训练流程。
- 两轮共计 46178 tokens。新对话来源仍保留原快照标识、读取时间和原文，没有把保存的笔记正文当成网页原文。

这证明成果和实际依据能跨对话复用，不证明模型所有解释都正确。回答仍把示例中的多 GPU/DeepSpeed 环境概括为训练必需条件，并对示例阅读器等条件有所扩大。未安装研究模型，也未测量实际科研人员节省工时。原始模型产物不作人工修正后冒充成功输出。
